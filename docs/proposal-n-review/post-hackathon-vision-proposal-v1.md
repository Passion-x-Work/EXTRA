## 0. 오너의 원문 의도 요약 (검증용 — 여기서 벗어나면 지적할 것)

1. **목적**: 역사를 재미있게 배우게 한다. 특히 *"이 사람이 왜 이렇게 했는지"* 를 알게 한다.
2. **형식**: 쇼츠 드라마식 **타임슬립** — 원래 스토리라인을 먼저 보여준 뒤, 내가 역사 속 한 인물로 들어간다.
3. **멀티플레이**: 여러 유저가 같은 장면에 모여 **함께 반박(역사를 이루게)** 하거나 **막는(이루지 못하게)** 편으로 나뉜다.
4. **카드 생성**: 실제 역사가 이뤄진 순간, 내 주장이 사료와 얼마나 매칭되느냐로 카드가 생긴다. **실패해도 카드가 생긴다.**
5. **카드 사용**: 말하는 대신 카드를 꺼내 "말한 것처럼" 쓸 수 있다.
6. **카드 획득 경로**: ① 스토리 진행 ② 게임 내 미니게임 ③ 직접 반박 게임 ④ 유료 구매.
7. **카드 성장**: 직접 변론 내용에 따라 새 카드 생성 또는 업그레이드.
8. **PvP**: 같은 장면의 다른 유저와 카드 배틀. 포켓몬 카드처럼 **수집 + 뽐내기**.
9. **인물 타임라인**: 세종이면 세종 생애의 여러 이벤트가 있고, 각 이벤트가 "제대로 이뤄지게" 하는 것.
10. **인물/장소 확장**: 세종에 한정하지 않음. 접근 쉬운 곳 어디든.
11. **오프라인 연결**: 그 장소에 **직접 가보고 싶게** 만든다.

## 1. 한 줄 컨셉

> **"역사는 이미 정해져 있다. 하지만 그 순간 누가 어떤 말을 했는지는 비어 있다. 그 빈칸에 네가 들어간다."**

플레이어는 사료에 이름이 남지 않은 **단역(EXTRA)** 으로 타임슬립해, 결정적 순간에 **역사를 이루는 편(正史)** 또는 **역사를 막는 편(反史)** 에 서서 말한다. 역사는 결국 실제대로 흘러가지만, **당신의 말이 사료와 얼마나 닿았는지**가 카드로 남는다.

### 왜 이 프레임이 오너 의도를 만족하는가
- "왜 이렇게 했는지" → 反史 편이 실제 반대파(최만리)의 논리를 **진지하게** 펼치고, 正史 편이 그걸 뚫어야 하므로 **양쪽 논리를 다 배우게 된다.** 한쪽 편만 있는 현재 구조보다 학습 깊이가 크다.
- 타임슬립 쇼츠 감성 → 각 장면이 "쇼츠 1편 = 1 이벤트" 단위. 인트로 클립(30~60초) → 개입 → 결과 클립.
- 멀티 → 正史/反史 진영전이 자연스러운 팀 구조.
- 카드 → 아래 §3.

## 2. 핵심 루프 (Core Loop)

```
[1] 장면 진입 (쇼츠형 인트로 30~60초: 원래 역사가 어떻게 흘렀는지 먼저 보여줌)
      ↓
[2] 진영 선택: 正史(이루게 하라) / 反史(막아라)  ※ 反史도 사료 기반이어야 카드가 나옴
      ↓
[3] 설득 라운드 (N턴, 실시간 or 비동기)
      - 직접 타이핑 변론  OR  보유 카드 제출("카드로 말하기")
      - AI 인물이 사료 근거로 반응, 게이지 변동
      - 같은 방에 있는 다른 유저의 발언도 인물이 함께 듣는다 (합의/충돌)
      ↓
[4] 역사 확정 (항상 실제 역사대로 종결. 게이지는 "얼마나 설득력 있게 도달했나"의 기록)
      ↓
[5] 정산: 내 발언 각각을 사료 매칭 → 카드 생성/업그레이드 (실패해도 생성)
      ↓
[6] 도감/컬렉션/공유 → 다음 이벤트 또는 다른 장소로
```

**중요한 설계 결정 (오너 확인 필요)**
- **역사는 바뀌지 않는다**를 원칙으로 제안. "역사를 바꾸는 판타지"가 아니라 "역사 속 빈칸을 채우는" 게임이라야 교육 목적과 사료 카드 시스템이 일관됨. 반대편(反史)이 이겨도 결과는 "그럼에도 역사는 이렇게 갔다 — 왜?"라는 **역사적 해설**로 마무리. 이게 오히려 "왜 이렇게 했는지"를 가장 강하게 각인시킴.
  - 대안: 反史 승리 시 짧은 "if 역사" 클립을 보여주고 원 역사로 복귀 (재미 요소, 하지만 오개념 리스크 있음 → 명확한 "가상" 라벨 필수).

## 3. 카드 시스템 설계

### 3.1 카드 = "사료와 닿은 발언의 결정체"

| 카드 종류 | 생성 조건 | 예시 |
|---|---|---|
| **사료 카드 (史料)** | 발언이 1차 사료 원문/논리와 직접 매칭 | "설총의 이두도 우리 표기가 아니냐" (세종실록 1444.2.20) |
| **논거 카드 (論)** | 사료 직접 인용은 아니나 시대 논리로 정합 | "백성이 억울함을 글로 아뢰지 못한다" |
| **인물 카드 (人)** | 특정 인물의 입장을 정확히 대변 | 최만리·정창손·신숙주 등 |
| **장소 카드 (地)** | 장면의 실제 장소·유물 관련 | 집현전·간송미술관(해례본)·여주 영릉 |
| **오답 카드 (誤)** | 사료와 불합치/시대착오 발언 — **실패에서도 생성** | "한글은 세계에서 가장 과학적인 문자" (후대 평가, 당대 논거 아님) → 뒷면에 "왜 틀렸나" 해설 |

- **오답 카드가 핵심 교육 장치**: 틀린 말도 카드가 되고, 카드 뒷면이 정정 해설. "실패했을 때도 카드가 생긴다"는 오너 요구를 교육적으로 뒤집은 것. 오답 카드는 PvP에서 상대 도발용/블러프용으로도 쓸 수 있게(재미).
- **등급**: 현행 5등급(탁월/정합/부분/불합치/역효과)을 카드 희귀도로 승격 — 탁월=금(SR), 정합=은(R), 부분=동(N), 불합치/역효과=오답(誤).
- **업그레이드**: 같은 논거를 더 정확한 사료 인용으로 다시 말하면 N→R→SR 승급. 직접 변론이 카드보다 항상 잠재 보상이 큼(타이핑 유인).

### 3.2 "카드로 말하기"
- 턴에 카드를 내면 그 카드의 대표 대사가 발언으로 처리. 게이지 효과는 카드 등급의 **80%** (직접 변론 대비 페널티 → 타이핑 유도, 그러나 초심자·모바일 진입 장벽 낮춤).
- 카드 + 짧은 덧말(30자) 조합 → "카드 강화 발언"으로 100%+α. 카드 게임과 대화 게임의 다리.

### 3.3 획득 경로 (오너 4경로 반영)
1. **스토리(솔로 캠페인)**: 인물 타임라인 이벤트 클리어 시 고정 카드 + 발언 기반 생성 카드.
2. **미니게임**: 사료 퀴즈 / 연표 맞추기 / "이 말 누가 했나" / 장소 사진 인식(§6). 저등급 카드·업그레이드 재료.
3. **직접 반박(라이브 방)**: 멀티 설득 라운드. 최고 가치 카드의 주 원천.
4. **구매**: **랜덤 뽑기 금지 권고**(교육 게임 + 미성년 + 규제 리스크). 대신 ① 장소/인물 **팩(확정 구성)** ② 카드 **꾸미기(프레임·일러스트 변형)** ③ 시즌패스. 카드의 *효과*는 돈으로 못 사고 *외형과 접근성*만 산다는 원칙.

### 3.4 수집·뽐내기
- 도감(현행 dogam) 확장: 인물별·장소별·시대별 컬렉션 %.
- **공유 카드 이미지**(현행 buildShareCard 활용): 카드 뒷면에 내가 실제로 친 문장 + 사료 출처 → SNS 공유 = 마케팅.
- 프로필 "대표 카드 3장" 전시.

## 4. 멀티플레이 설계 (가장 큰 신규 영역 — 단계적으로)

### 4.1 단계
| 단계 | 형태 | 기술 난도 | 비고 |
|---|---|---|---|
| **M0 (지금)** | 솔로 | — | 현행 |
| **M1 비동기 광장** | 같은 장면을 플레이한 사람들의 발언이 "조정 기록"으로 남고, 인물이 "지난 유저들의 말"을 참조 | 낮음 (DB 하나) | 멀티 느낌 + 서버 비용 최소. **1차 목표 추천** |
| **M2 진영전 방 (2~6인)** | 正史/反史 편으로 실시간 라운드 제. 인물 AI가 방 전체 발언 듣고 1회 응답 | 중 (WebSocket + LLM 1회/라운드) | 카드 PvP 여기서 |
| **M3 이벤트 레이드** | 특정 시간에 수백 명이 한 장면에 몰림, 진영별 총합 게이지 | 높음 | 시즌 이벤트용 |

### 4.2 PvP 카드 배틀 규칙 (M2)
- 라운드마다 각 진영이 카드 or 발언을 제출 → 인물 AI가 **"어느 쪽 말이 더 사료에 닿았나"**로 판정. 판정자는 유저가 아니라 **역사 인물** → 사료 정합성이 유일한 승부 기준. 억지 논리·현대어 남용·욕설은 자연스럽게 패배.
- 오답 카드 낸 상대에게 "그건 후대 평가다"라고 **직접 반박(타이핑)** 하면 상대 카드 무효 + 내 카드 생성 → 배틀 자체가 팩트체크 훈련.

### 4.3 LLM 비용/공정성 가드
- 방 단위로 라운드당 판정 1회(개별 발언은 임베딩 유사도로 1차 채점 → 현행 `server/rag/retrieve.js` 확장), 최종 응답만 LLM.
- 사료 매칭 채점은 결정론적 부분을 늘려 유저 간 불공정 시비 줄이기.

- **수원 화성** — 정조·정약용, "왜 화성을 지었나" (탕평·화성 천도설 논쟁). 사료(화성성역의궤) 풍부.
- **남한산성** — 인조·최명길 vs 김상헌, **주화 vs 척화** 논쟁 → 正史/反史 구조에 가장 딱 맞는 장면. 강력 추천 2호.
- **강화도** — 고려 대몽항쟁/병인양요. 
- **경주** — 신라 (사료 밀도 낮아 후순위).

### 5.3 콘텐츠 스키마 변경
- 현행 `content/characters/{figure}/{profile,knowledge,scenario,debate}.json` → **`content/scenes/{scene-id}/`** 로 장면 중심 재구성. 한 인물이 여러 장면, 한 장면에 여러 인물(세종+최만리).
- `debate.json`의 `issues[]` → 양 진영 논거로 확장: `stances: { orthodox: [...], heretic: [...] }` 각각 sourceRef 필수.
- 카드 정의 `content/cards/*.json` 신설 (id, type, rarity, sceneRef, sourceRef, frontText, backNote).

## 6. 오프라인(장소 방문) 연결

- **장소 카드**는 현장에서만 획득: GPS 체크인 or 안내판 QR/사진 인식 → 해당 장면의 SR 장소 카드 + 캠페인 보너스.
- 도감 한국 고지도(현행 지도 UI 재활용)에서 "방문함/미방문" 표시. 방문 시 핀이 채색됨.
- 현장 AR 대신 **"현장 쇼츠"**: 그 자리에서 인트로 클립을 다시 보면 "당시 이 자리에서…" 나레이션 변형. 저비용·고감성.
- 장기: 지자체·박물관(국립한글박물관, 수원문화재단) 제휴 → 카드 팩 후원. **B2G 수익 모델 후보**.

## 7. 교육 무결성 가드레일 (반드시 지킬 것)

1. **모든 카드에 sourceRef 필수.** 출처 없는 카드는 생성 불가(오답 카드는 "정정 근거"가 sourceRef).
2. 反史 진영의 논거도 **당대 실제 반대 논리**만 허용. 현대 관점의 반대("한글은 비효율적")는 오답 카드로 처리.
3. "if 역사" 연출 시 화면에 항상 **[가상]** 라벨.
4. 생존 인물·실명 사용 금지 유지(현 미야모토 정책 → 한국 집중이면 자연 해소).
5. 인물 AI 시스템 프롬프트에 "사료 밖은 '기록에 없다'로 답한다" 유지(현 하네스).
