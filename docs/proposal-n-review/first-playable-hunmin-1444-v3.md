# 「훈민정음, 1444」 첫 플레이 설계 v3

상태: 연출·플레이 가설. 아래 창작 대사는 역사적 인용이 아니며 실제 사료 발언으로 표시하지 않는다.
목표: 8~12분 안에 빙의, 생활 문제, 양측 우려, 자유 변론, 카드 습득과 재사용, 장소 연결을 한 번 경험.
전체 작품을 이 분량에 제한하지 않는다. 첫 수호자 튜토리얼 기준이며 교란자는 이후 다른 관점으로 진입.

## 장면 1. 낯선 이름 (약 1분)

눈을 뜨면 낯선 옷차림. 곁의 동료가 플레이어를 부른다. 플레이어는 자신이 문서를 전달하는 일을 돕는 사람의 역할에 들어왔음을 알아낸다.
창작 대사 후보: "멍하니 서 있을 때가 아니야. 네가 전할 문서잖아."

행동: 소매·이름표/소지품·문서를 차례로 확인. 탭으로 단서 열기, 대사 넘기기, 물건 자세히 보기 학습.
한 번에 세 단서 모두 강요하지 않고 필수 두 개 확인 후 진행. 설정/자막/음량 접근 가능.
이름·실제 직책·이름표 형태는 고증 전 미확정. 궁궐 출입 권한을 편의적으로 부여하지 않는다.
출력: "나는 지금 이 역할을 맡고 있다" 역할 카드. 전투 카드는 아님.

## 장면 2. 내가 한 말이 아닌데 (약 2분)

가상의 생활 인물이 자기 사정을 대신 적어달라고 부탁한다. 플레이어는 말로 들은 사정과 적힌 문서의 차이를 발견한다.
창작 대사 후보: "그렇게 말한 건 아닌데… 내가 읽을 수가 없으니, 맞게 적힌 건지도 모르겠소."
문자를 모르는 사람을 우스꽝스럽게 그리지 않으며, 한 사건으로 당시 모든 백성의 삶을 일반화하지 않는다.

미니게임: 구술의 핵심과 문서 요약 세 조각을 맞춘다. 원문 한문 지식 불필요, 현대어 재구성 사용.
목표는 정답 암기보다 누락된 의미 발견. 실패 시 강조·재청취 제공, 하트 소모나 진행 중단 없음.
왜 틀렸나 설명은 인물 대화와 한 줄 해설로 표현.
보상: 조사 단서 「제 뜻을 직접 전할 수 없다」. 아직 자동으로 강력한 전투 카드가 되지는 않음.

## 장면 3. 왜 반대하는가 (약 1~2분)

상소의 논점 하나를 현대어로 재구성해 보여준다. 기존 표기·학문과 새 문자의 관계를 왜 우려하는지 이해하게 한다.
최만리의 정확한 조항과 재구성 문구는 출처 검수 후 확정. 원문을 그대로 인용하지 않은 대사는 재구성 표시.

행동: "무엇을 걱정하는가?" 선택 후 출처 요약을 열어볼 수 있음.
나쁜 선택지 = 악당이라는 낙인이 아니라 다른 우려와 혼동한 선택지.
양측 질문 표시:
- 새 문자가 없으면 누구의 어려움이 남는가?
- 새 문자를 도입하면 무엇이 달라질 것을 우려하는가?

논쟁에 갈 경위는 별도 고증: 실제 회의에 평민이 자유롭게 출입했다는 식으로 표현하지 않는다. 첫 프로토타입은 시간여행 장치가 재구성한 가상 논쟁 공간으로 명시하는 방안도 비교한다.

## 장면 4. 첫 주장 (약 2분)

세종의 질문은 창작 재구성임을 전제로: "그대가 본 일을 말해 보라. 새 글자가 그 어려움과 무슨 관계가 있느냐?"
실제 역사 인용으로 쓰지 않는다. 플레이어가 세종에게 애민정신을 처음 가르치는 장면으로 만들지 않는다.

입력 선택:
- 직접 쓰기
- 말하기: 녹음 → 전사 확인/수정 → 제출
- 막막해요: 논점 칩과 문장 시작 도움

예상 입력: "대신 써주는 사람이 뜻을 바꿔도 읽지 못하면 확인할 수 없습니다. 자기 뜻을 직접 전할 길이 필요합니다."
AI 해석 미리보기: [논점: 의사 전달] [행동: 필요성 제시] [근거: 방금 경험한 창작 사건 / 관련 역사 자료 별도]
창작 사건 그 자체를 1차 사료로 분류하지 않음.

분기:
- 관련 주장: 같은 규칙의 행동으로 처리, 인물이 이유를 짚어 반응.
- 애매함: 두 논점 중 선택하도록 보완.
- 시대착오: 현재 장면에서 통하지 않는 이유 제시, 한 번 수정.
- 무관함/욕설: 효과 없음, 복귀 안내. 자동 계정 제재 없음.
- AI 장애: 준비된 논거를 골라 진행, 이번 해석을 완료하지 못했음을 안내.

사료 표현을 문자 그대로 맞추지 않아도 이해한 논리가 적절하면 인정. 기존 자료를 참고하되 1446년 서문과 1444년 장면의 시간 차이는 출처 표시에서 구분.

## 장면 5. 내 논거가 카드로 (약 1분)

유효한 주장을 습득 카드로 발급. 카드 원형 예시 「뜻을 전할 권리」는 현대적 명칭의 임시안이며 실제 당대 용어로 주장하지 않음.
대체 중립 제목 후보 「제 뜻을 전하는 길」.

앞면: 대표 논거·적용 논점·정해진 효과.
뒷면: 내 문장, 이번 사건, 관련 사료, 사실/재구성 구분.
발급 알림 → 카드 뒤집기 → 카드첩 1장 표시를 한 흐름으로 확인.
"방금 한 주장을 배웠습니다. 다음에는 다시 쓰지 않고 이 카드를 꺼내 말할 수 있습니다."

사료 원문을 복사했다는 이유만으로 최고 등급 부여하지 않음. 표현력·역사 지식이 낮아도 접근 가능하게 설계.
개인 카드 중복 발급 방지는 서버 요청 ID로 확인. 첫 로컬 모형은 테스트 데이터임을 표시, 실제 거래 재산과 분리.

## 장면 6. 다시 말하지 않아도 (약 1~2분)

후속 가상 논쟁에서 비슷하지만 다른 맥락의 질문이 나온다. 단순 동일 입력 반복보다 논거를 적용할 수 있는지 확인.
플레이어가 하단의 카드를 누르면 논거 요약과 효과 미리보기 → 사용 확정.
직접 드래그만 강요하지 않음. 모바일·키보드 접근 고려.
카드의 대표 대사가 내가 한 말처럼 표시되고 동일 규칙으로 효과 처리.
상대는 논점을 달리하는 대응을 보여줘 카드가 모든 문제를 해결하는 만능 열쇠가 아님을 전달.

이 단계에서 NPC 상대 1명으로 시작. 기술 실험에서는 다른 브라우저의 플레이어가 동일 행동을 수행.
첫 공개 소규모 방은 2대2 후보. 초보에게 여러 인물·규칙을 한 번에 노출하지 않음.

## 장면 7. 이야기 밖의 장소 (약 1분)

순서: 논쟁의 가상 결과 → 실제 역사와 비교 → 내 주장/출처 → 카드첩 → 장소 이야기 카드.
승패가 발언 타당성과 같지 않음을 보여준다. 패배해도 습득 카드 유지.

장소 카드는 실제 사건 발생지인지, 관련 유물/전시 장소인지 구분. 현재 건물과 당시 공간을 동일시하지 않음.
버튼: [카드첩 보기] [반대편 입장으로 도전] [관련 장소 알아보기].
방문 인증은 이 첫 제작 범위에 포함하지 않고 이야기 카드까지 구현.
후속 탐방에서는 공동 단서 퀘스트·도장·외형, 전투력 차이 없음.

## 화면 원칙

- 세로 모바일을 기본으로 데스크톱은 여백을 활용. 6명의 대사를 동시에 크게 띄우지 않음.
- 대사는 한 번에 한 초점, 전체 로그와 출처는 펼치기.
- 카드 사용과 직접 입력이 같은 행동 영역에 있음.
- 판정 엔진 이름은 사용자 화면이 아닌 개발 설정으로.
- 사료 / 현대어 재구성 / 창작 / 가상 결과 표시는 일관되게 제공.
- 음성만으로 정보를 전달하지 않음, 자막과 텍스트 대체 제공.
- AI 대기 중 상태 표시·취소/전환 제공. 준비된 반응을 실시간 AI처럼 속이지 않음.

## 첫 구현 전 고증 체크

1. 빙의 역할의 신분·직책·소지품과 문서 전달 동선.
2. 생활 사건의 사회적 개연성, 구술과 문서 사례의 표현.
3. 상소 조항의 정확한 내용·인물별 입장과 발언 귀속.
4. 1444년 장면에서 1446년 문헌을 인용하는 방식과 해설 분리.
5. 플레이어의 논쟁 참여를 실제 사건에 삽입할지, 명시적 가상 재구성 공간으로 할지.
6. 장소의 현재 관람 여부·건축 연혁·사건과의 정확한 관계.

## 수용 테스트

- 직접 입력으로 습득한 카드를 카드첩에서 확인하고, 다음 장면에서 사용 가능.
- 같은 논거는 직접 입력과 카드로 사용할 때 기본 효과 동일.
- 패배해도 개인 습득 보상이 소실되지 않음.
- 음성 오인식은 제출 전 수정 가능.
- 불확실한 추론을 거짓말로 단정하지 않음.
- NPC와 사람 모두 동일한 규칙·자원 제한을 적용, NPC는 상대 손패를 보지 않음.
- AI 실패·재접속·중복 제출에서 결과/보상이 중복되지 않음.
- 양측의 우려와 실제 역사 결과를 구분해서 설명 가능.

## 제외 범위

결제, 정식 거래소, GPS 체크인, 인플루언서 직접 출연, 실시간 생성 영상, 커뮤니티 승인 시스템, 글로벌 영구 역사 변경.
카드 원형 3~5종, 생활 미니게임 1종, 역사 인물 2명과 소수 가상 인물로 먼저 검증하는 안을 제안한다.
