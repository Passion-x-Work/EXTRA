# 스트레치: 재미요소 4종 (타이머·가짜엔딩·도감·캐릭터대비)

> **상태:** 스트레치(연기) · 미착수. MVP 이후 여력 될 때.
> **유래:** 미야모토 MVP 결정(Q) 중 정윤 아이디어로 나왔으나 스트레치로 연기됨.
> **작성:** 배정윤 · 정리 2026-08-08
> 관련 문서 : `docs/miyamoto-mvp-decisions.md`(Q6).

## S1. 타이머 (제한 시간 압박)

- **개념:** 반박 입력에 제한 시간을 둬 긴장감·몰입 부여.
- **적용 후보:** 역모드 논거당 카운트다운, 또는 정방향 턴 제한(난이도 옵션).
- **주의:** 교육/사고 유도 취지와 상충 가능(급하게 답하게 됨) → 하드 난이도
  한정 또는 on/off 옵션 권장. 밸런스 영향 큼.
- **확인 필요:** 어느 모드에 적용? 시간 값? 시간 초과 시 처리(자동 실패 vs 패스).

## S2. 가짜 엔딩 (페이크 결말)

- **개념:** 승리/종료처럼 보이는 가짜 연출 뒤 반전으로 진짜 국면 시작.
- **적용 후보:** 역모드에서 "설득당한 척" 하는 화자가 마지막에 한 번 더
  강하게 밀어붙이는 히든 논거, 또는 결과 화면 직전 페이크.
- **취지 연결:** "쉽게 넘어가지 마라 / 끝까지 의심하라"(arg-04 철학과 결).
- **확인 필요:** 트리거 조건? 1회성 vs 재플레이마다? 스포일러 관리.

## S3. 도감 (수집 요소 강화)

- **개념:** 카드 수집 컬렉션 확장 — 완성도·재플레이 동기.
- **관계:** 위 "내 말 다시보기 + 미야모토 도감" 및 v2 피드백 6번
  (전역 역사 인물 카드 수집)과 **중복/연계**. 통합 검토 필요.
- **확인 필요:** 별도 항목으로 유지할지, 위 도감 작업에 흡수할지.

## S4. 캐릭터 대비 (화자 간 대조 연출)

- **개념:** 하루(열정·유행) vs 쿠로다(냉정·데이터)의 성격 대비를 시각·연출로
  강조. 화자 전환 시 톤 차이가 확 느껴지게.
- **관계:** v2 피드백 5번(화자 전환 브릿지 연출) 및 현재 멀티턴 작업의
  mood 초상(neutral/pressing/smug/shaken)과 직결. 초상 16장 제작이 기반.
- **확인 필요:** 브릿지 연출 형태(내레이션 한 줄? 화면 전환 효과?), 대비를
  어디까지 살릴지.

## 정리 메모

- S3·S4는 이미 진행/제안 중인 작업(도감 연결, 멀티턴 mood 초상, 화자 브릿지)과
  겹침 → **독립 스트레치라기보단 기존 작업의 확장**으로 보는 게 맞을 수 있음.
- S1·S2는 신규 기능 성격 → 진짜 스트레치. 취지(교육·사고 유도)와의 정합성
  먼저 판단 후 착수 권장.
- ✅ **claw 전달 시:** 위 4종은 제목 기준 초안이므로, Q 원본 결정 내용과
  반드시 대조해 상세를 확정할 것.
