## 1. 현재 게임 진단 (2026-10-01 로컬에서 직접 플레이하며 확인)

### 1.1 실제 흐름 (세종, 미디움 난이도, Claude 판정)
1. **세계지도 화면**: 핀 3개(세종/고흐/미야모토)가 있고 "여기서 시작" 표시, 하단에 난이도 선택과 도감 버튼.
2. 세종 핀을 누르면 **검은 화면에 인트로 문장 5줄이 타이핑 효과로 나옵니다** (건너뛰기 가능).
3. **대화 화면**: 왼쪽에 세종 초상화, 배경은 편전 사진, 오른쪽은 채팅 로그. 상단에 신념 게이지(40부터), 설득의 축 칩 `?` 3개, 판정 엔진 선택(GPT/Claude), 정통/밈 말투 전환. 하단에 힌트 💡2와 입력창.
4. 테스트 결과:
   - "설총의 이두… 백성이 억울한 일을…"을 입력하니 **정합 +35**, 게이지 40에서 75로 올랐고, 축 하나가 "✓ 백성의 실용적 이익"으로 열렸으며, **"나의 논거 카드 획득 · 정합"** 알림이 떴습니다.
   - "한글은 세계에서 가장 과학적인 문자… 유네스코…"를 입력하니 **불합치 0**, 세종은 "흠, 그 말로는 나를 움직이기 어렵네"라고 답했습니다. **왜 틀렸는지 설명이 없습니다.**
5. 대화 중에 도감(🎴)을 열었더니 **"아직 모은 카드가 없어요"** 라고 나옵니다. 방금 받은 논거 카드는 `localStorage.extra_myarg_v1`에 저장되어 있는데 도감에는 보이지 않습니다.

## 2. 한 줄 컨셉

> **"누군가 역사를 비틀려 한다. 너는 그 순간으로 떨어진다. 지킬 것인가, 비틀 것인가."**

## 4. 게임 시스템

### 4.1 진영

| | 수호자 (守) | 교란자 (亂) |
|---|---|---|
| 목표 | 세종의 신념 게이지를 100까지 올린다 | 세종의 신념 게이지를 0까지 내린다 |
| 쓸 수 있는 논리 | 세종 쪽 사료 논리 (이두, 백성의 억울함, 운서) | **최만리 상소 6조의 실제 논리** (사대, 이적, 학문 쇠퇴, 형옥 등) |
| 쓰면 안 되는 논리 | 후대 평가 ("세계에서 가장 과학적") | 현대 관점 ("한글은 비효율적") |
| 배우는 것 | 세종이 **왜** 밀어붙였나 | 반대파가 **왜** 반대했나 (그들 나름의 합리성) |

- 두 진영의 쓰면 안 되는 논리는 모두 **오답 카드(誤)** 로 처리합니다 (§5.2).
- 콘텐츠 데이터에서 양 진영 논거는 `debate.json`의 `stances: { guardian: [...], disruptor: [...] }` 로 나누고, 각 논거에 `sourceRef`를 반드시 붙입니다.

### 4.2 라운드 흐름 (2막 라이브 방)

```
방 입장 (최대 6인: 수호자 3 + 교란자 3, 빈자리는 NPC)
  ↓
라운드 × 5  (라운드당 제한시간 60초)
  ├─ 각자 [직접 변론] 또는 [카드 1장 + 덧말 30자] 제출
  ├─ 카드 효과 → 정해진 규칙으로 즉시 계산 (§4.3)
  ├─ 직접 변론 → AI 판정 (등급) → 게이지에 반영 + 카드 생성/업그레이드 후보로 등록
  └─ 세종이 그 라운드 발언 전체를 듣고 한 번 응답 (AI 1회 호출)
  ↓
결과: 게이지 ≥ 100 수호 성공 / ≤ 0 뒤틀림 / 5라운드 후 50 기준 판정
  ↓
정산: 개인별 카드 생성·업그레이드, 게임머니 지급, 실제 역사 해설
```

### 4.3 카드 배틀 규칙 (정해진 규칙, AI 사용 안 함)

카드마다 고정된 수치와 속성이 있습니다.

| 필드 | 뜻 | 예시 |
|---|---|---|
| `power` | 게이지에 주는 기본 효과 | 수호 카드 +12, 교란 카드 −12 |
| `axis` | 논리의 축 (세종 기준 숨은 가치) | 백성 / 실용 / 학문 / 사대 / 형옥 |
| `counters` | 이 카드가 무력화하는 상대 축 | 「이두 선례」는 「사대」를 무력화 |
| `rarity` | 희귀도 N / R / SR / 誤 | |
| `cost` | 한 판에 쓸 수 있는 총량 제한 | 덱 비용 합계 10 이하 |

**계산 순서 (라운드마다)**
1. 양쪽 카드를 공개합니다.
2. **상성**: 내 카드의 `counters`에 상대 카드의 `axis`가 있으면 상대 카드 효과가 0이 되고, 내 카드는 효과가 ×1.5가 됩니다.
3. **축 보너스**: 세종의 숨은 가치 축(현행 "설득의 축")과 맞으면 효과 +50%. 수호자에게만 적용되며, 교란자는 "세종이 원래 두려워한 것"(예: 사대 질서와의 충돌) 축에서 +50%를 받습니다.
4. **오답 카드**: 효과는 크지만(±20), 상대가 **직접 타이핑으로 반박**해서 AI 판정이 "정합" 이상이 나오면 효과가 무효가 되고, 그 오답 카드를 낸 사람은 −10을 받습니다. 반박한 사람에게는 새 카드 후보가 생깁니다.
5. 게이지에 합산합니다.

> 모든 수치는 `config/cards-balance.json` 한 파일에 모아서 플레이테스트로 조정합니다.

### 4.4 직접 변론 (AI 판정)
- 현행 5등급(탁월 / 정합 / 부분 / 불합치 / 역효과)과 사료 매칭(`server/rag/retrieve.js`)을 그대로 씁니다.
- 판정 결과는 **① 게이지 반영 ② 카드 생성 후보 등록 ③ 카드 업그레이드 조건 확인** 세 가지에 쓰입니다.
- 공정성 보완:
  - 판정 시 AI 온도(temperature)를 0으로 고정하고, 판정 근거(어느 사료와 매칭됐는지)를 화면에 함께 보여줍니다.
  - 같은 방의 발언은 **한 번에 묶어서** 판정해서 기준이 흔들리지 않게 합니다.
  - 판정 결과가 이상하면 "이의 제기" 버튼 → 로그로 남겨 프롬프트 개선에 씁니다.

### 4.5 동시 접속자가 없을 때 (D6)
- 매칭 대기 15초 안에 사람이 안 모이면 선택지를 보여줍니다:
  - **[NPC와 함께]** (기본값): 빈자리를 NPC 동료와 NPC 상대가 채웁니다.
  - **[독대]**: 나와 세종 둘만. 현행 솔로 모드와 같습니다.
- 도중에 사람이 들어오면 **NPC 자리를 사람이 이어받습니다.**
- **NPC 설계**: 해커톤 때 만든 미야모토 역방향 엔진(`server/engine/miyamotoEngine.js`, 하루·쿠로다가 유혹하고 압박하는 멀티턴 구조)을 재활용합니다.
  - 교란자 NPC: 최만리, 정창손 등 **실존 반대파 인물의 말투**로 상소 논리를 던집니다. (역사 인물은 사료대로 말해야 하므로, NPC는 사료에 있는 논리만 씁니다.)
  - 수호자 NPC: 가상의 인물(예: 집현전 서리 "막동이")로, 초보자에게 힌트를 주는 역할도 합니다.
  - NPC는 **카드만 사용**합니다(AI 호출 비용 절감, 규칙 기반이라 예측 가능). 대사는 카드의 대표 대사를 씁니다.

## 5. 카드

### 5.1 카드 종류

| 종류 | 생기는 조건 | 예시 |
|---|---|---|
| **사료 카드 (史)** | 직접 변론이 1차 사료와 **직접 매칭** | 「설총의 이두」 (세종실록 1444.2.20) |
| **논거 카드 (論)** | 사료 인용은 아니지만 당대 논리로 **정합** | 「억울함을 아뢰지 못하는 백성」 |
| **인물 카드 (人)** | 스토리 진행 보상 | 최만리, 정창손, 신숙주, 성삼문 |
| **장소 카드 (地)** | 현장 방문 인증 (§7) | 경복궁 수정전(집현전 터), 간송미술관 |
| **오답 카드 (誤)** | 불합치·역효과 판정 (**실패해도 생김**) | 「세계에서 가장 과학적인 문자」 → 뒷면: "20세기 이후의 평가입니다. 1444년 조정에서는 쓸 수 없는 논리였습니다." |

- **모든 카드에는 `sourceRef`가 있어야 생성됩니다.** 오답 카드는 "왜 틀렸는지 알려주는 근거"가 `sourceRef`입니다.
- 희귀도: 탁월 = SR(금), 정합 = R(은), 부분 = N(동), 불합치·역효과 = 誤.

### 5.2 카드가 생기고 커지는 방법
1. **생성**: 판이 끝나면 내 직접 변론 중 판정 등급이 가장 높은 것 1~2개가 카드가 됩니다. 오답은 1장까지만 생깁니다.
2. **같은 논리 재발견**: 이미 가진 카드와 같은 축의 논리를 더 정확한 사료로 말하면 **업그레이드** (N → R → SR).
3. **나만의 문장**: 카드 뒷면에는 **내가 실제로 친 문장**이 새겨집니다. 같은 「설총의 이두」 카드라도 사람마다 문장이 달라서 모으고 자랑하는 이유가 생깁니다.
4. **미니게임 보상**: N 카드와 업그레이드 재료("사료 조각")를 줍니다.
5. **스토리 보상**: 인물 카드는 막을 클리어할 때 고정으로 줍니다.

### 5.3 카드로 말하기
- 턴에 카드를 내면 카드의 대표 대사가 **내가 말한 것처럼** 로그에 나옵니다.
- 효과는 §4.3 규칙대로 계산합니다. 카드만 내면 카드 생성·업그레이드는 일어나지 않습니다. **새 카드는 직접 변론에서만** 나오므로 타이핑할 이유가 계속 남습니다.
- **카드 + 덧말 30자**: 카드 효과는 규칙대로 계산하고, 덧말은 AI가 판정해서 "정합" 이상이면 보너스 +5 그리고 업그레이드 조건에 포함합니다.

### 5.4 거래 (D8)
- **게임머니("엽전")로만** 거래합니다. 현금으로 엽전을 사는 기능은 **만들지 않습니다.** (현금 → 엽전 → 카드 구조가 되면 사실상 현금 거래가 되기 때문입니다.)
- **가격 상한**: 희귀도별 기준가의 **최대 2배**까지만 올릴 수 있습니다 (예: SR 기준가 500엽전이면 최대 1,000엽전). 최소가도 있습니다(기준가의 0.5배).
- **거래 제한**: 새로 받은 카드는 24시간 후부터 거래할 수 있고, 하루 거래 횟수에 상한이 있습니다(작업장·매크로 방지).
- **1:1 교환**: 엽전 없이 카드끼리 교환할 수 있습니다. 희귀도 차이가 두 단계 이상이면 교환할 수 없습니다.
- **장소 카드는 거래 금지**입니다. 직접 가야만 얻는 카드라서 거래되면 방문 동기가 사라집니다.
- **뒷면 문장**은 거래 후에도 남습니다(원작자 표시). 카드의 역사를 보여주는 수집 요소가 됩니다.
- **엽전을 얻는 곳**: 판 참여, 미니게임, 뒤틀린 역사 복구, 일일 과제.

### 5.5 외형 (유료화 후보, 구현은 나중에 — D7, D9)
- 카드 프레임(한지, 금박, 단청), 일러스트 변형, 뒷면 서체, 도감 테마.
- 효과에는 절대 영향을 주지 않습니다.
- 이번 범위에서는 **외형을 바꾸는 시스템만** 만들고, 무료로 얻는 외형 2~3종으로 구조를 확인합니다. 결제는 D9에 따라 나중에 정합니다.

### 8.2 화면 구조 재설계

**① 첫 화면: 세계지도 → 한국 "시간 균열 지도"**
- 조선 고지도 위에 **균열(뒤틀린 장면)** 이 표시되고, 그 옆에 "지금 N명이 이 장면에서 싸우는 중"이 보입니다.
- 장소 카드를 얻은 곳은 색이 칠해집니다.
- 해외 인물 핀은 숨깁니다(데이터는 보존).

**② 인트로: 텍스트 → 쇼츠 세로 화면**
- 9:16 세로 컷 3~5장 + 자막 + 효과음 (예: "1444년 2월 20일. 한 장의 상소가 올라온다." → 최만리 컷 → 세종 컷 → 화면 균열 → "당신은 어느 편인가?").
- 해커톤 때 쓴 승리 클립 인코딩 방식(webm + mp4 폴백)을 그대로 씁니다. 처음에는 정지 이미지와 켄 번스 효과(천천히 확대되는 연출)로 충분합니다.
- 진영 선택은 **카드 두 장을 뒤집는 연출**(守 / 亂)로 합니다.

**③ 대화/배틀 화면: 오른쪽 채팅 → "조정(朝廷)" 무대 구조**
```
┌────────────────────────────────────┐
│  [수호] 나 · 막동이(NPC) · ○   ▓▓▓▓▓▓░░ 신념 게이지 ░░  [교란] 최만리(NPC) · ○ · ○  │
│                         세종 (가운데, 크게)                         │
│              세종의 대사 말풍선 (한 번에 1개, 크게)                   │
│   ─────────── 이번 라운드에 나온 발언/카드가 양쪽에서 날아와 부딪힘 ───────────   │
│  [내 패: 카드 5장 부채꼴]       [직접 변론 입력창]   ⏱ 42초  라운드 2/5   │
└────────────────────────────────────┘
```
- **세종을 가운데**에 두고 양 진영을 좌우에 배치해 **대립 구도가 한눈에** 보이게 합니다(U9).
- 로그 전체는 기본적으로 접어두고 **"기록 보기"** 로 엽니다. 화면에는 지금 라운드만 크게 보여줍니다(U7).
- 게이지는 **가운데에서 좌우로 밀고 당기는 줄다리기 형태**로 바꿉니다. 수호 쪽 끝 = 100, 교란 쪽 끝 = 0.
- **라운드와 남은 시간**을 항상 보여줍니다(U12).
- 판정을 기다리는 동안 세종의 "생각하는 표정" + **"전하께서 숙고 중이십니다…"** 연출(U13).

**④ 카드 연출 (U4)**
- 획득: 화면 중앙에 **카드가 뒤집히며 등장** → 희귀도에 따라 빛(동/은/금), 誤 카드는 붉은 도장 "誤"가 찍히는 연출.
- 앞면: 카드 일러스트 + 대표 대사 + 수치(power, axis). 뒷면: 사료 출처 + **내가 친 문장** + 해설.
- 내 패: 하단에 부채꼴로 펼치기, 끌어서 올리면 제출.

**⑤ 결과/정산 화면**
- 순서: **실제 역사 해설**(짧은 쇼츠 1컷) → 내 발언 중 사료와 맞은 문장 하이라이트 → 카드 개봉 → 엽전 → "이 장소에 가보기".
- 공유 카드(현행 `buildShareCard`)는 세로 9:16 비율로 바꿔 쇼츠·스토리에 바로 올릴 수 있게 합니다.

**⑥ 도감 → "카드첩"**
- 탭 구분: 사료 / 논거 / 인물 / 장소 / 오답.
- 장면별 수집률(%) 표시, 빈칸은 실루엣으로 보여서 "무엇이 남았나"를 알게 합니다.
- 프로필에 **대표 카드 3장** 전시.

## 9. 기술 설계

### 9.1 현재 구조
- 프론트: Vite + 순수 JS. `web/src/app.js` **한 파일에 83KB**가 들어 있습니다(정방향, 역방향, 도감, 결과, 공유가 섞여 있음).
- 서버: `server/index.mjs` (Node, 판정 프록시 + 정적 파일 제공). 저장은 브라우저 `localStorage`만 사용.
- 배포: Render 무료 플랜 (처음 접속할 때 30초~1분 대기).

### 9.2 1차 목표에 필요한 것

| 영역 | 제안 | 이유 |
|---|---|---|
| 실시간 방 | **Colyseus** (Node용 멀티플레이 서버) 또는 Socket.IO | Colyseus는 방, 상태 동기화, 재접속, 매칭을 기본 제공하고 Node라서 현행 서버와 같은 언어 |
| DB와 로그인 | **Supabase** (Postgres + 인증) | 카드 소유, 거래, 엽전은 서버에서 관리해야 조작을 막음. 무료로 시작 가능 |
| 카드 규칙 엔진 | `shared/rules/` 순수 함수 모듈 | 서버(정답)와 클라이언트(미리보기)가 같은 코드를 씀 |
| AI 판정 | 현행 `server/ai/judge.js` 확장 | 온도 0, 라운드 단위로 묶어 판정 |
| 프론트 | `app.js`를 화면별 모듈로 분리. 프레임워크 도입은 선택 (Svelte 권장, 가볍고 현행 순수 JS에서 옮기기 쉬움) | 카드 패, 배틀 무대처럼 상태가 많은 화면이 늘어남 |
| 호스팅 | 게임 서버: Fly.io 또는 Railway (WebSocket 상시 연결, 콜드스타트 없음). 프론트: Vercel | Render 무료 플랜은 잠들기 때문에 실시간 방에 부적합 |


### 9.4 서버가 반드시 맡아야 할 것 (조작 방지)
- 카드 생성, 업그레이드, 거래, 엽전 증감은 **서버에서만** 합니다. 클라이언트는 요청만 보냅니다.
- 배틀 계산도 서버에서 합니다(클라이언트 계산은 미리보기용).
- 현행 `localStorage` 저장은 로그인 없는 "게스트 모드"용으로만 남기고, 로그인하면 서버로 옮깁니다.

### 9.5 AI 비용 추정 (대략)
- 한 판(5라운드) = 세종 응답 5회 + 직접 변론 묶음 판정 5회 = **AI 호출 약 10회**. NPC는 카드만 써서 추가 호출 없음.
- 미니게임은 AI 호출 0회.
- 직접 변론 판정은 저렴한 모델, 세종 응답은 좋은 모델로 나눠 비용을 줄입니다.
