## 개요

승리 클립을 세종 전용에서 **전 인물로 확장**합니다.
고흐/하루/쿠로다 댄스 챌린지 영상을 클립으로 분할했고,
역모드 패배 시에는 킹받는(kingbada) 클립이 도발 대사와 함께 나옵니다.

## 변경 사항

### 🎬 클립 인코딩 (22파일, 약 8MB)
- 고흐/하루/쿠로다 댄스 영상 → 각 3구간(2~3초, 구간 겹침) 분할
- 포맷: **webm(VP9+Opus) 우선 + mp4(H.264+AAC) 폴백** — 아이폰/Safari 대응
- 각 구간의 원본 소리 그대로 포함
- 하루/쿠로다 kingbada 영상은 통짜(6.7초) 인코딩

### 🏆 승리 클립 확장
- `vangogh`: GH 클립 3개 중 랜덤
- `miyamoto`(역모드): **하루 3개 + 쿠로다 3개 통합 풀에서 랜덤** (요청 반영)
- 기존 세종 동작 변화 없음, 클립 없는 인물은 영상 영역 미표시(기존 규약 유지)

### 😤 역모드 패배 클립 (보너스)
- 패배 시 **나를 꺾은 화자**의 kingbada 클립 재생 — 기존 "킹받는 엔딩" 도발
  대사와 세트로 복수심 재도전 루프 강화
- 원치 않으면 `revShowResult`의 `showRevLoseClip()` 한 줄 제거로 롤백 가능

## 확인 방법
1. 고흐 승리 → GH 클립 랜덤 재생 확인
2. 미야모토 승리 → 하루/쿠로다 클립이 판마다 다르게 나오는지 확인
3. 미야모토 패배 → 마지막 화자의 kingbada 클립 + 도발 대사 세트 확인
4. (가능하면) 아이폰 Safari에서 mp4 폴백 재생 확인
