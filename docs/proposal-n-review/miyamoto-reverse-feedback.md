## 1. [✅ 해결됨 · `017773d`] arg-04 조기 종료 (밸런스 버그)

- **증상:** arg-04("출처를 의심하라") 방어 직후, 성공 메시지도 '결과 보기'
  버튼도 없이 화면이 멈춘 것처럼 보임. arg-05("모두의 재미")가 아예 안 나옴.
- **원인(코드 확정):** `REV_START=40` + `onDefend` 누적으로 arg-04에서 게이지
  100 도달 → `win=true`로 조기 종료. arg-05가 설계상 도달 불가였음.
- **해결:**
  - (프론트/A패치) 종료 게이트(showEndGate) + 컨페티를 역모드 `revEnd`에도
    적용 → 종료 시 '결과 보기 ▶'와 승리 연출 정상 표시.
  - (조기 종료 제거) `onReverseTurn`에서 `gauge<=0`·`r.win` 조기 판정 삭제 →
    5논거 전부 진행 후 최종 게이지로만 승패 판정(arg-05 항상 노출).
  - **검증:** 20→35→50→70→90→100, arg-05 노출 후 '철학을 지켰다' 승리.

## 2. [설계 · 미해결] 되묻기/질문 처리 + 논거당 멀티턴 설득

> v1의 "단순 질문에도 즉시 채점" 지적을 두 갈래로 분리합니다.
> **현재 코드 동작:** `onReverseTurn`은 입력을 무조건 반박으로 간주해 즉시
> 채점하고, 논거 1개 = 대사 1회 = 판정 1회 = 곧바로 다음 화자로 전환합니다.
> 논거당 1턴만 존재하며, AI의 재설득·되묻기 대응이 없습니다.

### 2a. 되묻기(질문) 처리 — 채점하지 않기

- **상황:** "왜 그러길 바래?" 처럼 **되물었을 뿐인데** 방어 점수가 매겨지고
  다음 논거로 넘어감.
- **문제:** 되묻기(정보 탐색)와 실제 반박(동의/거절)이 구분되지 않음.
- **제안(최소안):** 되묻기로 판단되는 입력은 **채점 없이** 상대 답변만 돌려주고
  게이지 불변. (질문 vs 반박 분류 = judge 로직 변경 수반)

### 2b. 논거당 멀티턴 설득 — AI가 여러 번 시도

- **정윤 의도:** 플레이어가 안 넘어오거나 방어에 성공하면, 하루/쿠로다가
  **각도를 바꿔 1~2회 재설득**을 시도해야 한다. 논거 하나를 여러 턴에 걸쳐
  완전히 막아내야 "방어 완료"로 넘어가는 구조.
- **현재:** 논거당 1턴으로 끝나 밀당(설득 공방)이 없음.
- **제안:** 논거마다 `retries`(재설득 대사 1~2개)를 데이터로 두고, 방어 성공 시
  다음 각도의 대사를 던짐. 모두 막으면 그 논거 방어 완료.
- **⚠️ 밸런스 재계산 필요:** 현재 5논거 × 1턴 = 5턴 게임. 논거당 2~3턴이면
  10~15턴으로 길어짐 → `onDefend`/`onComply` 수치, 데모 분량 전부 재조정.
- **판단 필요:** 구현 규모가 큼 → 별도 브랜치에서 진행 권장(정윤 계획).

## 3. [✅ 해결됨 · `017773d`] `/api/judgeReverse` 엔드포인트 부재

- **v1 현황:** 역설득용 `/api/judgeReverse` 핸들러가 없어 `fetch`가 항상 404,
  오프라인 `judgeRebuttal`로만 판정됨.
- **해결:** `api/judgeReverse.js` 신규 추가(`judgeRebuttal` 서버 호출) +
  `vercel.json` `includeFiles`에 content 포함 → 배포 시에도 역판정 사용 가능.
- **⚠️ 후속 확인:** provider가 gpt/claude일 때 `miyamotoEngine.judgeRebuttal`이
  실제 LLM 호출을 하는지(현재 오프라인 키워드 판정만인지) 검증 권장.

## 4. [✅ 해결됨 · `017773d`] 게이지 3중 불일치 — 값 통일

- **v1 현황:** `app.js`(40/60) · `cards.json`(0/100) · Q1(20/80) 3중 불일치로
  arg-04 이전 승리 도달, arg-05 미출현.
- **해결:** `cards.winCondition`을 **단일 출처**로 통일 (`startGauge=20`,
  `goalGauge=80`, `winAfterAllArgs=true`). `app.js`는 이 값을 읽고, 하드코딩
  `REV_START`/`REV_PASS`는 폴백 상수(`REV_START_DEFAULT`/`REV_GOAL_DEFAULT`)로만 잔존.
- **참고(밸런스):** onDefend 합계 85 + 시작 20 = 최대 105(→100). 전부 방어 시
  100으로 승리선 80 통과. 단 **arg-04(가짜 명언, -20 동조) 실패 시 승리 빡빡** —
  의도된 함정 난이도로 보이나 플레이테스트에서 좌절감 여부 확인 권장.

## 5. [설계 · 미해결] 화자 전환 시 상황 설정 부재

- **상황:** 한 화자(하루) 채점 후 **곧바로** 다른 화자(쿠로다) 등장.
  장면 전환·상황 설명·연출이 없어 맥락이 끊김.
- **제안:** 화자 전환 시 짧은 브릿지 연출/내레이션 삽입.
  (예: "쿠로다가 끼어든다 —" 한 줄, 또는 화자별 등장 문구를 데이터로)

## 6. [아이디어 · 전역 · 미해결] 완주 보상 = 역사 인물 카드 수집

- **제안:** 모든 난이도 클리어 또는 100% 달성 시, 해당 **역사 인물 카드**를
  수집 보상으로 지급.
- **⚠️ 미야모토 한정 아님 — 세종·고흐 등도 적용 요망 (전역 기능).**
- **의도:** 사료 카드(도감)와 별개로 "이 인물을 완전히 정복했다"는 컬렉션
  목표를 만들어 재플레이 동기 부여.
- **연계:** 기존 도감(localStorage) 구조에 '인물 카드' 컬렉션을 하나 더 얹는
  형태로 확장 가능. 스트레치 범위로 검토.
