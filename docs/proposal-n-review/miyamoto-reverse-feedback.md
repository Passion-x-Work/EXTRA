# 미야모토 역설득 — 플레이 피드백 & 개선 제안 (배정윤)

> 브라우저 플레이 테스트 중 발견. 1·2는 프론트에서 수정/대응 예정,
> 3~5는 설계·서버·밸런스 판단이 필요해 공유합니다.

## 1. [수정중] arg-04에서 게임이 조기 종료됨 (밸런스 버그)

- **증상:** arg-04("출처를 의심하라") 방어 직후, 성공 메시지도 '결과 보기'
  버튼도 없이 화면이 멈춘 것처럼 보임. arg-05("모두의 재미")가 아예 안 나옴.
- **원인 (코드 확정):**
  - `app.js`: `REV_START = 40`, 방어마다 `onDefend`(+15/+20) 누적.
    40 → 55 → 70 → 90 → **110(→100 clamp)**. arg-04에서 게이지가 100 도달.
  - `miyamotoEngine.js`: `win = nextGauge >= (winCondition.goalGauge || 100)`.
    goalGauge=100이라 arg-04에서 `win=true` → 그 자리에서 승리 종료.
  - 즉 **arg-05는 설계상 도달 불가**. 5논거 방어 의도와 어긋남.
- **조치(프론트):** 종료 게이트(showEndGate) + 컨페티를 역모드 `revEnd`에도
  적용 완료 → 종료 시 '결과 보기 ▶'와 승리 연출은 이제 정상 표시됨.
- **⚠️ 남은 문제(밸런스, 결정 필요):** 아래 4번 참조.

## 2. [설계] 단순 질문에도 즉시 채점됨 — 동의/거절 단계 필요

- **상황:** 하루 논거에 "왜 그러길 바래?"라고 **되물었을 뿐인데** 방어 점수가
  매겨지고 다음 논거로 넘어감.
- **문제:** 되묻기(정보 탐색)와 실제 반박(동의/거절)이 구분되지 않음.
- **제안:** 한 논거 안에서 **질문 → 캐릭터 답변 → 그때 동의/거절(반박)** 흐름 고려.
  최소안: 되묻기로 판단되는 입력은 채점 없이 상대 답변만 돌려주고 게이지 불변.
- **판단 필요:** 질문 vs 반박 분류는 judge 로직 변경 수반 → 유나님 판단 필요.

## 3. [서버] `/api/judgeReverse` 엔드포인트 부재

- **현황:** `api/judge.js`에는 정방향 `judge`만 있고 역설득용
  `/api/judgeReverse` 핸들러가 없음.
- **결과:** `onReverseTurn`의 `fetch("/api/judgeReverse")`가 항상 404 →
  catch로 빠져 **오프라인 `judgeRebuttal`로만 판정**되고 있음.
  (현재 데모는 오프라인 판정으로만 동작 중. LLM 판정 미적용.)
- **요청:** 역모드에도 LLM 판정을 쓰려면 서버에 `judgeReverse` 엔드포인트 추가 필요.
  (`miyamotoEngine.judgeRebuttal`을 서버에서 호출하는 형태)

## 4. [밸런스] 게이지 3중 불일치 — 값 통일 필요

- **현황:** 세 군데 값이 서로 다름.
  - `app.js`: `REV_START=40`, `REV_PASS=60` (잠정)
  - `cards.json` winCondition: `startGauge=0`, `goalGauge=100`
  - Q1 결정(리뷰 답변): start 20 / win 80
- **문제:** onDefend 합계(15+15+20+20+15 = **85**) 기준으로,
  start 20/win 80이든 start 40/goal 100이든 **arg-04 이전에 승리 도달** →
  arg-05가 안 나옴.
- **결정 필요:** 5논거를 모두 방어해야 승리하도록 하려면
  (a) win 임계를 "모든 논거 소진 후 판정"으로 바꾸거나,
  (b) onDefend 값을 낮춰 arg-05까지 80/100에 못 미치게 조정.
  Q1(20/80)과 정합되도록 `cards.winCondition`으로 값을 일원화 권장.

## 5. [설계] 화자 전환 시 상황 설정 부재

- **상황:** 한 화자(하루) 채점 후 **곧바로** 다른 화자(쿠로다) 등장.
  장면 전환·상황 설명·연출이 없어 맥락이 끊김.
- **제안:** 화자 전환 시 짧은 브릿지 연출/내레이션 삽입.
  (예: "쿠로다가 끼어든다 —" 한 줄, 또는 화자별 등장 문구를 데이터로)

## 6. [아이디어 · 전역] 완주 보상 = 역사 인물 카드 수집

- **제안:** 모든 난이도 클리어 또는 100% 달성 시, 해당 **역사 인물 카드**를
  수집 보상으로 지급.
- **⚠️ 미야모토 한정 아님 — 세종·고흐 등도 적용 요망 (전역 기능).**
- **의도:** 사료 카드(도감)와 별개로 "이 인물을 완전히 정복했다"는 컬렉션
  목표를 만들어 재플레이 동기 부여.
- **연계:** 기존 도감(localStorage) 구조에 '인물 카드' 컬렉션을 하나 더 얹는
  형태로 확장 가능. 스트레치 범위로 검토.
