## 1. 인물 라인업 변경 ⭐(핵심 결정)

기존 **세종 · 검투사 · 호쿠사이** → **세종 · 반고흐 · 미야자키(비전)** 로 변경.

- **검투사 제외** — 설득 축(임무)을 잡기 애매해 의미가 약함.
- **호쿠사이 제외** — 국내 인지도가 낮아 심사위원·첫 유저가 "이게 누구?" 할 위험.
- **유럽 축 = 반고흐** — (검투사가 로마=유럽이었던 자리를) 문화·예술 인물로 대체. 퍼블릭 도메인이라 자유 사용.
- **일본 축 = 미야자키 하야오 / 지브리** — NHN 일본 진출 주요국 전략과 정합, 애니메이션 인지도 높음.
  - 단, **저작권·개인정보 때문에 실제 게임으로는 안 만듦.** "일본 = 준비 중"으로만 표시.
  - **비전용**으로 기획안에 넣음: *미래에 라이선스 콜라보 → 전 세계 팬이 최애 창작자를 게임으로 만난다.*

## 2. 실제 제작 범위

- **게임은 2개만 제작**: **세종 = 완성형(제대로)**, **반고흐 = 가오픈/프리오프닝(맛보기)** 수준.
- **미야자키 = 실제 개발 X**, "준비 중" + 비전 슬롯.
- 이유: 예선이라 스코프 집중. 기본은 **"한국 메인게임"**(역사에 끼어드는 조력자 단역극)에 초점.

## 3. 난이도 시스템 ⭐(배정윤 아이디어, 채택)

- **이지 / 미디엄 / 하드** 3단계.
- **이지**: 아는 걸로만 자유롭게 대답(힌트 카드 없음). 통과하면 **관련 역사 사실을 '카드'로 보상 지급.**
- 그 **카드로 공부해서 다음 난이도(미디엄)** 를 깬다. 이지에서 통하던 대답은 미디엄에선 **안 통함.**
- **카드 = 도감 형식으로 수집** → 모으는 재미 + 리플레이.
- 효과: **역사를 몰라도 놀면서 배우는 구조**(교육 플랫폼 명분).
