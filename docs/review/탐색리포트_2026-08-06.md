## 4. 발견된 이슈

| 이슈 | 설명 |

| **백엔드 판정 실패 (HTTP 500)** | `/api/verdict` 호출이 500 에러. 백엔드 서버 미실행 + API 키 미설정 |

## 5. 전체 평가

- 한지풍 배경 + 세종 초상 + 채팅형 인터페이스 조합이 잘 어우러져 있음
- 밈/정통 말투 전환이 재미있는 포인트
- 풀 기능을 보려면 `npm run server`로 백엔드 + `.env`에 API 키 설정 필요
- 에셋 활용도 개선 필요 (BG 분리, Phase별 캐릭터 분리 등)
