# 🎮 미야모토 캐릭터 기획 제안 — "철학을 수집해 그 사람이 되다"

## 1. 한 줄 요약

기존 세종이 "**플레이어가 AI를 설득하는**" 게임이라면,
미야모토는 "**AI가 플레이어를 설득하고, 플레이어는 그 논거의 진위를 판단해 수집하는**" **역방향 캐릭터**다.
진짜 철학 카드를 모아 게이지 100을 채우면 → **"당신은 이제 미야모토처럼 생각한다"**.

---

## 2. 왜 이 컨셉인가 (강점 3가지)

- **카드 도감 컨셉과 완벽히 결합**: 우리가 이미 정한 "사료 = 카드 수집" 메커니즘에서,
  여기서는 **수집 대상이 '철학 논거 카드'**가 된다. 두 컨셉이 하나로 합쳐짐.
- **교육적 서사**: 단순 퀴즈가 아니라, 플레이어가 미야모토의 사고방식을 **내면화**하며
  "그 사람이 되어가는" 성장 서사. → NHN 심사 어필 포인트(게임 업계 전설 소재).
- **가짜 명언 리스크를 콘텐츠로 전환**: 유명하지만 미야모토가 안 한 말("지연된 게임…")을
  **함정 카드**로 활용 → "유명하다고 사실은 아니다"라는 교훈까지 전달.

---

## 3. 지식재산권 / 초상권 검토 (리스크 낮음)

| 위험 | 회피 방법 |
|---|---|
| 캐릭터 IP(마리오·젤다) | **안 씀.** 인물의 철학·발언만 다룸 → 저작권 문제 없음 |
| 초상권 | **플레이어=미야모토 본인(1인칭)** → 미야모토 얼굴 화면에 안 나옴. 그림 필요 없음 |
| 인격권·명예 | 진짜 카드 = **검증된 실제 발언만**, 가짜 카드 = "미야모토가 안 한 말"이라 **명시** |

- ⚠️ **생존 인물**이므로 (1) 지어낸 대사 금지, (2) 부정적 희화화 금지 원칙 유지.
- ⚠️ 실명 사용 가능 여부는 **NHN 해커톤 규정 확인 권장**.

## 4. 등장하는 가상 AI 캐릭터 2인 (그림 필요한 건 이들뿐)

> 플레이어(미야모토)를 설득하는 두 목소리. 실존 인물 아님 → 자유롭게 디자인 가능.

### 🔥 AI-A. 열정 신입 개발자 "하루"
- **역할**: 트렌드·마감·유행을 대변. "요즘 이게 대세예요!" "빨리 내야 해요!"
- **성향**: 에너지 넘치지만 성급함. **함정 카드(가짜 트렌드 논거)를 자주 던짐**.
- **기능**: 플레이어를 흔드는 유혹 담당. 그럴듯한 오답을 매력적으로 포장.

### 🧊 AI-B. 냉정한 프로듀서 "쿠로다"
- **역할**: 수익·시장·현실 논리로 설득. "이게 돈이 됩니다" "리스크가 큽니다".
- **성향**: 논리적이고 압박감 있음. 진짜와 가짜를 **논리적으로 섞어** 던짐.
- **기능**: 판단 난이도 담당. 냉철해서 오히려 그럴듯한 함정을 만듦.

> 두 캐릭터가 **서로 다른 방향으로 설득** → 플레이어는 양쪽에서 오는 논거를
> 각각 판단해야 함 (트렌드 유혹 vs 시장 논리). 게임에 긴장과 다양성 부여.

## 6. 유나님께 확인할 것 (개발 판단)

1. **엔진 호환성**: 이 "논거 카드 수집(진짜/가짜)" 방식을 기존 applyGrade가 처리 가능한지, 아니면 로직 추가가 필요한지. (각 카드에 점수가 붙어 있어 세종과 유사)
2. **판정 방식**: 진짜/가짜를 AI가 실시간 판정 vs JSON에 미리 정답 정의 후 엔진 채점. → 미리 정의가 안정적·저비용 (추천).
3. **라인업 결정**: 미야모토를 미야자키와 별개 4번째로 넣을지, 아니면 미야자키 자리를 미야모토로 교체할지. (둘 다 일본 창작자라 겹칠 수 있음. "게임 회사" 컨셉엔 미야모토가 더 맞을 수도.)
4. **실명 사용**: NHN 규정상 실존 인물 실명 사용 가능한지 확인 필요.
