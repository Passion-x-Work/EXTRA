출처 티어 원칙을 지켰고, 발문이라는 1차 사료가 캐릭터의 핵심 신념과 정확히 맞물린다는 점에서 세종보다 오히려 근거가 단단해 보입니다.

다만 **게임으로 만들 정황**이라는 관점에서 보면 지금 구조엔 치명적인 구멍이 하나 있습니다.

## 가장 큰 문제: 설득할 게 없습니다

문서 상단의 대상 장면을 그대로 읽으면 이렇습니다 — "호쿠사이는 아직 진짜 화가가 되지 못했다고 여기며 더 정진하려 한다. 플레이어는 그가 죽는 날까지 붓을 놓지 않도록 논거를 공급한다."

즉 **설득 목표를 캐릭터가 이미 원하고 있습니다.** 세종 케이스는 최만리라는 외부 반대와 "명분이 없다"는 실질적 압력이 있어서 게이지가 오르내릴 여지가 있었는데, 호쿠사이는 시작부터 의지가 100입니다. 플레이어가 "계속 그리세요"라고 하면 "그럴 참이네"로 끝나요. 설득 게임의 기본 조건인 *저항*이 없습니다.

게다가 이 구조에선 게이지 0~15 '냉담' 구간을 정당화할 방법이 없습니다. 왜 냉담하죠? 이유를 사료에서 못 만들면 그냥 캐릭터가 심술궂은 노인이 되어버립니다.

## 해결안 세 가지 (2안 추천)

**1안 — 저항의 축을 현실로 옮기기.** 의지는 있지만 접어야 할 이유가 산더미인 상태로 세팅합니다. 이걸 뒷받침할 사료가 실제로 존재하는데, 리서치 문서엔 빠져 있습니다. 손자의 도박빚을 떠안아 만년 내내 궁핍했다는 기록(British Museum 연표, Sotheby's), 60대 후반 중풍으로 붓을 못 잡을 뻔했다가 직접 만든 유자 약으로 회복했다는 『갈식북재전』 일화, 1820년대 후반 딸과 아내를 잃고 커미션이 거의 끊겼던 침체기 — 이 셋이 반론 축으로 훌륭합니다. 플레이어는 "계속하라"가 아니라 "이 상황에서도 계속할 이유"를 대야 하죠.

**2안 — 판정 룰을 뒤집기 (이게 제일 재밌습니다).** 1834년 시점의 호쿠사이는 이미 「후지산 36경」으로 대가 소리를 듣습니다. 주변은 "이만하면 됐다"고 하죠. 그런데 본인은 "일흔 전 그림은 볼 것이 없다"고 씁니다. 그러니까 이 인물에게는 **칭찬이 독이고 도발이 약**입니다. "선생님은 이미 최고입니다" → 게이지 하락. "선생의 파도는 물의 형태를 흉내 냈을 뿐, 아직 살아 있지 않습니다" → 게이지 상승.

세종은 근거와 예의가 함께 필요한 캐릭터인데 호쿠사이는 정반대 룰이 됩니다. 판정 기준을 config로 분리해둔 우리 구조의 강점을 심사위원에게 보여주기에 이보다 좋은 대비가 없어요. "인물마다 설득의 문법이 다르다"가 한 줄로 설명됩니다.

**3안 — 결단을 하나로 좁히기.** "죽는 날까지 정진"은 검증 가능한 단일 사건이 아닙니다. 대신 "「후지산 백경」 초편 발문에 저 선언을 쓸 것인가"로 좁히면 승리 조건이 명확해지고, 보상 카드 뒷면에 **실제 발문 원문**을 그대로 넣을 수 있습니다. 사료가 곧 보상이 되는 구조라 세종의 훈민정음 서문과 대칭도 맞습니다.

개인적으로는 2안을 뼈대로, 1안의 반론 축(빚·병·나이·세상의 만족)을 저항 재료로 쓰고, 3안으로 승리 조건을 정의하는 조합을 권합니다.

## 사실관계에서 고칠 것

**티어 표기 오류가 두 군데** 있습니다. hokusai-006(임종 어록 "5년만 더")을 티어 1(전)로 적었는데, 이건 1893년 이지마 교신의 『갈식북재전』에 실린 전승이고 브리태니커는 3차 자료입니다. 티어 3 또는 별도 '전승' 등급으로 내려야 우리 RESEARCH_POLICY와 어긋나지 않습니다. 마찬가지로 "호 30번·이사 93번"도 출처를 [B][E]로 달았지만 원 출처는 전부 『갈식북재전』의 "移居九十三所" 기록이에요. 기관이 인용했다고 1차가 되는 건 아니니 "메이지기 전기 기록, 통설" 정도로 표기하는 게 안전합니다.

**나이 표기 기준**이 없습니다. 발문의 "일흔셋", "여든", "백열"은 전부 세는나이(数え年)입니다. 발문 자체도 세는나이 75세 때 쓴 글이고요. 세종 문서에서 정한 표기 원칙과 통일해서 "73세(세는나이, 만 71~72세)" 식으로 못 박아두지 않으면 나중에 카드 텍스트와 대사에서 숫자가 어긋납니다.

**발문 인용이 축약되면서 한 단계가 빠졌습니다.** 원문은 팔십에 더 나아가고, 구십에 그 깊은 뜻을 궁구하고, 백에 신묘의 경지, 백열에 점획이 살아 숨쉰다는 4단 구조인데 문서엔 90이 뭉개져 있어요. 이 문장이 게임의 핵심 논거이자 승리 텍스트가 될 가능성이 높으니, "본선 전 보강"으로 미루지 말고 지금 와세다대 고전적종합데이터베이스나 국립국회도서관 디지털컬렉션에서 초편 원본을 확보해 원문·번역을 확정하는 게 좋겠습니다.

**빠진 사료 중 아까운 것들**로는, 1839년 화재로 평생 모은 스케치를 다 잃고 붓만 쥐고 뛰쳐나왔다는 일화(설득 성공 이후의 에필로그로 완벽합니다), 그리고 만년에 오부세의 후원자 다카이 고잔에게 가서 83세와 89세에 천장화를 그렸다는 기록(British Museum도 언급하는, "죽는 날까지 정진"이 실제로 실행되었다는 물증)이 있습니다. 후자는 승리 보상 텍스트로 그대로 쓸 수 있습니다.

## 이미지·저작권

인물과 작품이 퍼블릭 도메인인 건 맞지만, **소장 기관의 사진 이미지 라이선스는 별개**입니다. Met는 오픈액세스(CC0)라 상업적 사용까지 자유롭지만, British Museum 이미지는 비상업 조건이 붙습니다. 해커톤 제출물은 상업성 판단이 애매하니 참고 이미지는 Met 쪽으로 통일하는 게 깔끔합니다.

한편 좋은 소식은, 세종과 달리 호쿠사이는 만년 자화상이 전한다고 알려져 있어서 얼굴 근거 문제가 훨씬 가볍다는 점입니다. 다만 어느 기관 소장인지는 제가 확실히 기억하지 못하니 확인이 필요합니다. 확인되면 세종 때 겪은 "표준영정 회피" 고생을 안 해도 됩니다.

## 스키마·문서 정합성

세종은 profile / knowledge / debate / scenario 4개 JSON으로 쪼개놨는데 이 문서는 md만 있고 JSON에 필요한 필드 — 말투 샘플, 회피 응답 문구, 금기 주제, 5단계 표정 텍스트, 이미지 프롬프트 세트 — 가 전부 없습니다. 사료 조각도 세종은 8개인데 여기는 6개고, 그나마 6개 중 4개가 "정진"이라는 같은 이야기예요. 논거 다양성이 부족해서 게이지 5단계를 자연스럽게 못 밟습니다. 위에 말한 반론 축(빚·병·나이·세상의 만족)으로 두세 조각을 채워 8개로 맞추는 걸 권합니다.

밈 왜곡 방지 관점에서 하나 더. 「가나가와 앞바다의 파도」는 쓰나미로 오해되는 경우가 많고, 발문 문구는 자기계발 명언으로만 소비됩니다. 플레이어가 "포기하지 마세요, 백 살까지 하시면 돼요" 같은 인용구 복창으로 게이지를 올릴 수 있으면 안 되니, 판정 룰에 "발문 문구 자체를 되돌려주는 논거는 가점 없음"을 넣어두면 좋겠어요.

```json
      "예시": "이만하면 충분합니다 / 더 하실 필요 없습니다" },
    { "조건": "근거없는비난", "점수": -8,
      "설명": "작품명이나 구체적 결함 없이 깎아내리기만 함" },
    { "조건": "발문복창", "점수": 0,
      "설명": "발문 문구를 그대로 되돌려주는 논거는 가점 없음 (밈 왜곡 방지)" }
  ]
}
```

> 핵심은 "비판하면 오른다"가 아니라 **"근거 있는 비판만 오른다"**.
> 근거 없이 깎아내리면 -8로 더 크게 떨어진다. 그래야 욕설 대회가 되지 않는다.

**게이지 5단계 대사**

| 구간 | 단계 | 대사 |
|---|---|---|
| 0-15 | 냉담 | "또 칭찬인가. 그 말은 내 붓을 늙게 하네." |
| 15-45 | 무관심 | "다들 그렇게 말하지. 그래서 나는 다들 잊어버렸네." |
| 45-70 | 관심 | "……지금 뭐라 했나. 물의 무게? 다시 말해보게." |
| 70-90 | 수긍 | "자네, 눈이 나쁘지 않군. 나도 그게 걸렸네." |
| 90-100 | 감복 | "일흔셋에 겨우 골격을 알았네. 여든에는 더 나아갈 걸세." |

**튜토리얼 처리 — 오에이(응위) 힌트**
이 룰은 플레이어가 처음엔 반드시 틀린다. 그게 의도된 설계.
첫 턴 실패 후 딸 오에이가 힌트를 준다.

> "아버지께 잘한다고 하면 안 돼요. 아직 못 한 걸 말해주세요."

오에이는 만년까지 함께 살며 그림을 그린 화가라 등장 근거가 충분하고,
현재 지적된 **힌트 UI 부재 문제**도 함께 해결된다.

**장점**
- "판정 기준을 config로 분리한 구조"의 가치가 한 화면에 증명됨 → 심사 어필
- 세종과의 대비가 극적. 반전 규칙은 리뷰에서 거의 항상 잘 먹힘
- 근거가 티어1 발문 하나로 충분

**단점**
- 판정 프롬프트 템플릿에 `판정문법` 분기 필요 (유나님 작업 반나절 추가)
- 첫 플레이 이탈률 위험 → 오에이 힌트가 필수

# 3안 — 발문을 쓰게 하라

**설계 한 줄**
승리 조건을 단일 문서로 좁힌다. 플레이어의 논거가 그대로 발문의 문장이 된다.

**상황**
「후지산 백경」 초편 판목이 다 새겨지고 발문 한 장만 비어 있다.
출판사는 "간단히 감사 인사만 쓰시죠"라고 한다.

**결단**
이 빈 페이지에 무엇을 쓸 것인가.
관례대로 인사말인가, 여든·아흔·백 살의 자신을 선언할 것인가.

**독특한 메커니즘 — 종이가 채워진다**
화면 오른쪽에 빈 종이가 있고, 게이지 단계마다 발문이 한 줄씩 완성된다.

| 구간 | 종이에 나타나는 문장 |
|---|---|
| 40 (시작) | (백지) |
| 45-70 | "나는 여섯 살부터 사물의 형상을 그리는 버릇이 있었다" |
| 70-90 | "일흔셋에 이르러 겨우 새와 짐승, 벌레와 물고기의 골격과 초목이 나는 이치를 조금 깨달았다" |
| 90-100 | "여든에는 더욱 나아가고, 아흔에는 그 깊은 뜻을 궁구하며, 백 살에 이르러 신묘의 경지에 이를 것이다. 백열 살이면 점 하나 획 하나가 살아 있는 듯하리라" |
| 실패 (0-15) | "갑오년 봄, 화공 호쿠사이 삼가 적다." (관례적 인사말만) |

> 위 번역문은 **가안**. 원문 대조 후 확정 필요.

**판정 규칙 초안**
플레이어의 논거가 발문의 어느 구절과 의미상 대응하는지를 Claude가 매핑한다.
8조각 RAG 직접 매핑 구조를 그대로 쓰되, 조각을 "사료"가 아니라 "발문의 각 구절"로 놓는다.

```json
{
  "승리조건": "발문_4단_완성",
  "매핑조각": [
    { "id": "hokusai-p1", "구절": "육세부터의 버릇",        "대응논거": "재능이 아니라 습관" },
    { "id": "hokusai-p2", "구절": "칠십 이전은 볼 것 없다", "대응논거": "과거 부정" },
    { "id": "hokusai-p3", "구절": "칠십삼세에 골격을 깨닫다", "대응논거": "최근의 진전" },
    { "id": "hokusai-p4", "구절": "팔십·구십·백·백십",     "대응논거": "미래 계획" }
  ],
  "실패조건": "4구절 중 2개 이하 매핑 시 관례적 인사말로 종료"
}
```

**장점**
- 승리/패배가 시각적으로 명확
- 카드 보상이 곧 사료 원문 → 세종의 훈민정음 서문과 완벽한 대칭
- "사실은 사료, 말투는 자유" 슬로건이 가장 잘 드러남
- **시연 영상 제작이 압도적으로 쉬움** (종이가 채워지는 장면 하나로 끝)

**단점**
- 반론 축이 약해 대화가 심심할 수 있음
- 발문 원문 4단 확보가 선결 조건 (현재 90세 단계 누락)
