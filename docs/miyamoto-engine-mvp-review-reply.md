# 미야모토 엔진 MVP 리뷰 — 결정사항 정리 (Q1~Q6)

> 담당: 배정윤 / 유나님 리뷰 문서(`docs/miyamoto-engine-mvp-review.md`)에 대한 응답
> 상태: 전 항목 결정 완료

## Q1. 게이지 수치
- **결정: 시작 20 / 승리 80 동의.**
- `onDefend` 합이 85라, 시작 20이면 5개 논거 중 4개만 방어해도 승리선(80)에 닿으니, 하나 정도 comply(동조)로 삐끗해도 리커버 가능.
- 논거를 6~7개로 늘리는 안은 밸런스 QA 재수행이 필요해 보여서 보류.

## Q2. 논거 순서
- **결정: MVP는 고정 순서(arg-01 → arg-05)에 동의. 셔플은 스트레치.**
- `test/miyamoto-balance.mjs`가 고정 순서 기준 26/26(100%)로 맞춰져 있음. 셔플 넣으면 게이지 누적 밸런스가 흔들릴 것 같음.
- 다른 캐릭터(세종/반고흐/호쿠사이) balance-qa도 전부 고정 시나리오 기준. 미야모토만 셔플 넣으면 팀 내 일관성 깨질 것으로 보임.

## Q3. 하루/쿠로다 비주얼
- **결정: 엔진·데모 먼저 안정화 후 이미지 생성 동의. `ASSETS_GUIDE` 그대로 사용.**
- 가이드의 "파일 없으면 자동 숨김 + 임시 그라디언트" 처리 덕분에 이미지 0장 상태로도 데모 안 깨질 것으로 확인.
- 미야모토용 `ASSETS` 한 줄만 추가필요해 보임(별도 문서안만들고,,):

```js
miyamoto: { dir: "Miyamoto", bgDark: "Miyamoto-BG02", bgLight: "Miyamoto-BG01", classic: "Miyamoto", meme: "Hip-Miyamoto" },
```

- ⚠️ 주의(메모): 미야모토는 역설득이라 **화자 2명(하루/쿠로다)**. 현 가이드는 "인물당 초상 1세트" 전제이므로, 이미지 부착 시 `ASSETS`를 speaker별 초상 매핑까지 확장 필요(가이드 §5 소폭 수정).

## Q4. 밈 모드
- **결정: 지금 한 번에 넣음(어차피 하게 될 것 같은데, 두 번에 나누지 않는게 낮지 않을까 함).**
- `judge.js`에 `tone === "meme"` 분기(MEME 리액션 풀)가 이미 존재 → 코드 추가 비용 거의 없을 것 같고,,
- `ASSETS_GUIDE` §2가 애초에 정통/밈 2종을 한 세트로 전제(`Hip-` 접두 규약 기존재).
- 가이드 §1 자동 숨김 처리로, 밈 초상 이미지가 아직 없어도 안 깨지니, "밈 모드 넣기"가 "밈 이미지 지금 제작"할 필요 없어서,, 혹시 못하면, 그때 삭제 또는 숨기는게 나아보임.
- 즉, 판정 톤 토글 + `ASSETS`의 meme 접두 + `Hip-` 규약은 지금 한 번에 반영. 밈 초상 5장 제작만 다른 에셋과 함께 나중에(자동 숨김 의존).

## Q5. 스코프 (재미요소 4종)
- **결정: 타이머·가짜엔딩·도감·캐릭터대비 → 스트레치로 미룸. 동의.**
- MVP는 판정 루프 하나에 집중.
- 단, **아이디어 확장은 미리 문서화**가 어떨지. 그리고 도감은 현재 "왜 수집하는지 의미가 약한" 상태로 보임 → 스트레치 진입 시 **성취각인형**(탁월/정합 받은 논거만 카드로, 플레이어가 쓴 설득이 카드에 기록)으로 재설계 방향 별도 아이디어 문서에 기록 예정.

## Q6. 출처 확인 (§4)
- **결정: 판정 루프 MVP에선 직접 인용문 미표시, `aiLine`(각색 대사)만 사용 → 출처 리스크 회피.**
- 직접 인용을 화면/도감에 띄우기로 확정되는 시점(스트레치)에 원문 정밀 대조.
