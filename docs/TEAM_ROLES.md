## 2. 김유나 — 개발 · 엔진 · AI 판정

**책임:** 게임이 실제로 돌아가게 만드는 전 영역.

### 실제로 맡아 구현한 영역

- **게임 엔진** (`server/engine/applyGrade.js`) — 신념 게이지·턴·승패·결과 등급을 결정론적으로 계산. "AI는 배우, 판정은 엔진" 원칙 구현.
- **AI 판정 하네스** (`server/ai/judge.js`) — GPT function calling / Claude tool use 구조화 판정 + 오프라인 휴리스틱 폴백. 등급 기준, 시대착오 감지, 인물 사칭 차단, 밈 격리 등 판정 지시문 설계.
- **RAG** (`server/rag/retrieve.js`) — 쟁점–사료 직접 매핑 검색과 출처 각주 노출.
- **역설득 모드 통합** — 배정윤이 설계한 엔진을 게임 흐름에 결합. 판정 프롬프트 분기(현대 말투), 멀티턴 공방, 카드 재사용 감쇠, 밸런스 조정.
- **웹 프런트엔드** (`web/`) — 비주얼 노벨 레이아웃, 게이지 연동 표정 전환, 난이도·힌트, **사료 도감/카드 시스템**(플립 카드·등급·꺼내 쓰기), 결과 카드, 지도 화면(오리지널 SVG 세계지도 · 위경도 기반 핀 배치 · 무한 스크롤), 모바일 반응형.
- **배포 구성** — 서버리스 판정 함수(`api/judge.js`, `api/judgeReverse.js`) + Vercel 설정.
- **문서** — 게임 소개서, AI 활용 기술 문서, 기능명세서, 회의록.

## 3. 배정윤 — 아트 · 영상 · 콘텐츠 · 리서치

**책임:** 게임에 담길 실제 콘텐츠와 비주얼, 그리고 그 사실 근거.

### 실제로 맡아 구현한 영역

- **캐릭터 이미지** (`web/public/Assets/`) — 세종·반 고흐·하루·쿠로다의 **설득 단계별(Phase 1~5) 초상**, 정통/밈 톤별 시리즈, 배경. AI 생성 후 보정·누끼·webp 파이프라인.
- **연출 영상** — 난이도별(이지/미디움/하드) 승리 클립, 패배 시 놀림 클립, 역설득 모드 듀오 클립 제작·편집.
- **인물 데이터 설계** (`content/characters/*/`) — `profile / knowledge / debate / scenario` JSON 구조. "인물 = 파일" 확장 구조 설계.
- **역설득 엔진 설계** (`server/engine/miyamotoEngine.js`) — 번외 모드의 반박 판정 로직, 멀티턴 공방, 밸런스 테스트(`test/miyamoto-*.mjs`) 작성.
- **사료 리서치** (`docs/research/`) — 1·2티어 근거로 세종 창제·반박 국면, 반 고흐 서간 기반 근거 정리. 미야모토 가짜 명언의 **오귀속 출처 추적**.
- **UX 리뷰** — 모바일 레이아웃, 카드 크기·가독성, 지도 시선 유도 등 개선 요구 정리.
- **문서** — VISION(확장 비전), RESEARCH_POLICY(사료 정책).

## 4. 공동 담당

- **기획** — 게임 컨셉, 난이도 설계, 카드·도감 교육 루프, 정통/밈 토글, 결과 카드.
- **인물 설계** — 가치 축(통하는 가치)·숨은 조건·대사 톤.
- **QA** — 상호 리뷰, 플레이테스트, 밸런스 점검.

## 5. 협업 · 분업 방식

- **저장소** — GitHub(`Passion-x-Work/EXTRA`) 단일 저장소. 기능별 브랜치 → **Pull Request → 코드 리뷰 → 머지**.
- **인터페이스 우선 합의** — 데이터 스키마(`content/characters/*`)와 판정 계약(등급 스키마)을 먼저 정하고, 각자 자기 영역을 병렬로 구현했다. 덕분에 아트·데이터 작업과 엔진 개발이 서로를 기다리지 않았다.
- **역할 경계** — 비주얼 에셋은 배정윤이 단독 소유(코드에서는 파일명 규약으로만 참조), 게임 로직은 김유나가 단독 소유. 충돌 지점을 구조적으로 없앴다.
- **소통** — 실시간 메신저로 즉시 피드백, 정기 통화로 결정 사항 확정. 주요 결정은 `docs/meeting-*.md`에 기록.
- **AI 도구 분업** — 코드는 Claude Code, 비주얼은 이미지/영상 생성 도구, 자료 조사는 Genspark로 각자 영역에 맞는 도구를 사용했다.
