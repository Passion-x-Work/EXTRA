# EXTRA · 게임 소개 및 설명서

**엑스트라(EXTRA)** — 역사에 끼어든 **단역**이 되어, 실존 인물을 대화로 설득하는 교육형 웹게임
NHN AI 해커톤 · 팀 **덕업일치(Passion × Work)** · 김유나 · 배정윤

---

## 1. 한 줄 소개

유적을 고르면 그 시대의 **실존 인물**이 소환된다. 당신은 역사의 **이름 없는 단역**으로 그 장면에 끼어들어, 인물이 흔들리는 순간 **좋은 논거를 건네** 그가 실제로 내린 역사적 결단으로 밀어준다.

## 2. 이런 게임이에요

- **글쓰기가 아니라 추리.** 승부를 가르는 건 문장력이 아니라 *"이 인물이 무엇을 가치 있게 여기는가"* 를 읽어내는 관찰력이다. 그 조건(숨은 가치)은 공개되지 않는다.
- **인물마다 통하는 축이 다르다.** 세종에게 통하는 말이 반 고흐에겐 역효과다. 매 인물이 새로운 자물쇠가 된다.
- **지어내지 않는 인물.** 인물의 모든 대사는 **검증된 사료에 근거**하며, 답변마다 출처가 붙는다.

---

## 3. 게임 방법

### 3-1. 목표

인물의 **신념 게이지**를 채우면 승리한다. 플레이어는 자유 서술로 논거를 입력하고, 판정 결과에 따라 게이지가 오르내린다.

| 인물 | 유적 · 국면 | 시작 게이지 | 승리 조건 |
|---|---|---|---|
| **세종대왕** | 경복궁 · 훈민정음 반대 상소 | 40 | 100 도달 |
| **빈센트 반 고흐** | 생레미 · 붓을 놓을지 고민하는 국면 | 30 | 100 도달 |
| **미야모토 시게루** (번외) | 역설득 모드 | 20 | 논거 5개를 모두 겪은 뒤 80 이상 |

### 3-2. 종료 조건

게임은 아래 두 가지 중 하나로 종료되며, 어느 쪽이든 **결과 화면**으로 이동한다.

- **승리(종료)** — 신념 게이지가 승리 기준에 도달. 결과 카드와 함께 사료 카드를 획득한다.
- **패배(종료)** — 신념 게이지가 **0**에 도달하거나, 유효하지 않은 논거가 **6턴 연속** 누적될 때. 인물의 놀림 대사와 함께 재도전할 수 있다.

번외(역설득) 모드는 논거 5개를 모두 겪으면 종료되며, 그 시점의 게이지가 80 이상이면 승리다.

### 3-3. 조작

마우스/터치와 **텍스트 입력**만으로 진행한다. 별도 키 조작은 없다.

| 조작 | 설명 |
|---|---|
| 지도에서 핀 선택 | 유적(인물)을 골라 입장. 모바일은 첫 탭에 이름 확인, 두 번째 탭에 입장 |
| 입력창에 논거 입력 → 전송 | 한 턴이 진행된다 |
| 💡 사료 힌트 | 막혔을 때 사료 힌트를 연다(난이도별 예산 소모) |
| 📖 도감 | 대화 중에도 도감을 열어 모은 카드를 **논거로 꺼내 쓴다** |
| 정통 / 밈 토글 | 인물 말투를 사극체 ↔ 요즘 말투로 즉시 전환(역사 사실은 불변) |
| 난이도 선택 | 이지 / 미디움 / 하드 |
| ← 뒤로가기 | 진행 상황이 자동 저장되고 지도로 나간다 |

### 3-4. 한 턴의 흐름

```
[지도] 유적 선택 → [인트로] 상황 제시 → [대화] 논거 입력
     → 판정: 등급 + 인물 대사 + 사료 출처 → 게이지·표정 변화
     → 게이지 도달 시 [결과 카드] 등급·낙관 → 사료 카드 획득 → [도감] 수집
```

판정 등급은 5단계이며, 등급이 곧 게이지 변화량이다.

| 등급 | 탁월 | 정합 | 부분 | 불합치 | 역효과 |
|---|---|---|---|---|---|
| 게이지 | **+50** | +35 | +15 | 0 | **−20** |

### 3-5. 결과 등급

승리까지 걸린 턴 수로 결정된다. **S**(2턴 이내) · **A**(4턴) · **B**(6턴) · **C**(그 외)

### 3-6. 번외 — 역설득 모드 (미야모토 시게루)

방향이 반대인 모드다. **AI가 플레이어를 설득**하고, 플레이어는 그 유혹과 함정을 **반박해 자신의 철학을 지켜낸다.**

- 동료 AI 두 명(**하루** — 열정 신입 / **쿠로다** — 냉정한 프로듀서)이 5개의 논거를 던진다.
- 논거 중에는 **실제로는 미야모토가 한 적 없는 가짜 명언**(오귀속)이 섞여 있다. 출처를 의심해야 막을 수 있다.
- 한 논거당 최대 2회 공방. 잘 막으면 **철학 카드**를 얻고, 동조하면 게이지가 깎인다.

### 3-7. 수집 요소 — 사료 도감 · 카드

- **사료 카드** — 승리하며 만난 실제 사료가 카드로 쌓인다. 카드 앞면은 **획득 당시 말투(정통/밈)에 맞는 인물 이미지**이고, 누르면 뒤집혀 사료 원문과 출처가 나온다.
- **철학 카드** — 역설득 모드에서 방어에 성공하면 획득. 반박 등급에 따라 **골드(탁월) / 실버(정합) / 브론즈** 로 나뉘고, 더 잘 막으면 등급이 올라간다.
- **카드 꺼내 쓰기** — 대화 중 도감을 열어 모은 카드를 논거로 재사용할 수 있다. 단, 재사용은 보상이 60%로 감쇠한다.

### 4-1. 플레이 링크 (권장)

> **웹 플레이:** `※ 배포 링크 기입 예정`
> 링크 접속만으로 **설치·로그인 없이 즉시 플레이**된다. 모바일·PC 반응형 웹.

### 4-2. 소스에서 직접 실행

**요구 사항:** Node.js 18 이상, npm

```bash
git clone https://github.com/Passion-x-Work/EXTRA.git
cd EXTRA
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

**AI 판정 사용 (선택)** — API 키가 없어도 **게임은 완전히 플레이된다.** 키가 없으면 오프라인 휴리스틱 판정으로 자동 폴백하며 게임 루프·게이지·승패가 모두 정상 동작한다. 실제 AI 판정을 쓰려면 프로젝트 루트에 `.env`를 만들고 키를 넣은 뒤 판정 프록시를 함께 실행한다.

```bash
# .env
AI_PROVIDER=gpt
OPENAI_API_KEY=sk-...
```

```bash
node server/index.mjs   # 판정 프록시 (기본 8787 포트)
```

## 6. 왜 특별한가

1. **능동적 설득·추론** — 감상·수집이 아니라 플레이어가 직접 가치를 판단하고 논거를 고른다.
2. **실존 인물 + 고증 교육가치** — 가상 캐릭터가 아니라 검증된 사료에 근거한 실제 인물.
3. **사료 근거(RAG) + 출처 표시** — "지어내지 않는 NPC." 고정 대사로는 불가능한, **AI 없이는 존재할 수 없는 게임.**
4. **역방향 모드** — AI가 플레이어를 설득하고 사람이 진위를 판별하는 구조로, 같은 엔진을 뒤집어 재사용했다.

## 7. 기술 요약

모바일 반응형 웹(Vite + 바닐라 JS) + 서버리스 판정. **핵심 원칙은 "AI는 배우, 판정은 엔진"** — AI는 등급과 대사만 내고 게이지·승패는 결정론 코드가 소유한다. 상세는 **AI 활용 기술 문서** 참고.
