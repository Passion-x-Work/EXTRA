# EXTRA · 게임 소개서

**엑스트라(EXTRA)** — 역사에 끼어든 **단역**이 되어, 실존 인물을 대화로 설득해 역사적 결단을 이끌어내는 교육형 웹게임.
NHN AI 해커톤 · 팀 **덕업일치(Passion × Work)** · 김유나 · 배정윤

---

## 1. 한 줄 소개

유적을 고르면 그 시대의 **실존 인물**이 소환된다. 당신은 역사의 **이름 없는 단역**으로 그 장면에 끼어들어,
인물이 흔들릴 때 **좋은 논거를 건네** 그가 실제로 내린 역사적 결단으로 밀어준다.

## 2. 이런 게임이에요

- **글쓰기가 아니라 추리.** 승부를 가르는 건 문장력이 아니라 *"이 인물이 무엇을 가치 있게 여기는가"* 를 읽어내는 관찰력.
  그 조건(숨은 가치)은 공개되지 않는다.
- **인물마다 통하는 축이 다르다.** 세종에게 통하는 말이 다른 인물에겐 역효과. 그래서 매 인물이 새로운 자물쇠가 된다.
- **지어내지 않는 인물.** 인물의 모든 대사는 **검증된 사료(1·2티어)에 근거**하고, 답변마다 출처가 붙는다.

## 3. 어떻게 하나요

```
[지도] 유적 선택  →  [소환] 인물 등장·첫 대사  →  [대화] 논거 입력 → 인물 반응 + 신념 게이지 변화 + 사료 출처
      →  게이지를 채우면 [승리]  →  [결과 카드] 등급·낙관 → 저장·공유(도전장)
```
- **모바일·PC 반응형 웹.** 링크만 열면 **로그인 없이 즉시 플레이.**
- 막히면 **사료 힌트**가 열리고, 승리하면 만난 사료가 **도감**에 모인다 — 놀며 공부하는 구조.

## 4. 등장 인물

| 인물 (유적) | 공략 축 | 상태 |
|---|---|---|
| **세종대왕** (경복궁 · 조선) | 애민 · 실용 | **완성** — 훈민정음 반대 상소 국면 |
| **빈센트 반 고흐** (생레미 · 프랑스) | 감정 · 색 · 정진 | **맛보기** — 붓을 놓을지 고민하는 국면 |
| **가쓰시카 호쿠사이** (에도 · 일본) | 정진 · 자연의 참모습 · 예술 그 자체 | **맛보기** — 노년에 붓을 놓으려는 국면 (하드) |
| **미야자키 하야오** (일본) | — | **콜라보 비전** (준비 중 · 생존 인물/IP는 정식 개발 제외) |

## 5. 특징

- **난이도 3단계** (이지 / 미디움 / 하드) — 역사를 몰라도 이지부터, 아는 만큼 하드로. 인물별 기본 난이도도 다르다(세종=튜토리얼 · 반고흐=표준 · 호쿠사이=하드).
- **비주얼 노벨 연출** — 좌측 인물 · 우측 대화의 2단 화면. **신념 게이지에 따라 인물의 표정(Phase)이 실시간으로 바뀐다** — 설득이 먹히는지 얼굴로 보인다.
- **사료 힌트 (+보너스)** — 막히면 사료 힌트가 열리고, 이지 클리어 등 보상으로 힌트가 추가된다(예산제).
- **사료 도감 · 카드 보상** — 설득하며 만난 실제 사료가 카드로 쌓인다(수집·복습).
- **정통 / 밈 말투 토글** — 진지한 사극체 ↔ 요즘 말투. 토글 즉시 인물 어투가 바뀐다. 단, **역사 사실은 어떤 모드에서도 불변.**
- **결과 카드 · 도전장** — 승리 장면을 이미지 카드로 저장·공유. 숨은 조건은 가려 도전장이 성립.
- **사료 출처 각주** — "이 답변의 근거: 훈민정음 해례본 서문" 처럼 대사마다 출처를 노출.

## 6. 왜 특별한가

1. **능동적 설득·추론** — 감상·수집이 아니라 플레이어가 직접 가치를 판단하고 논거를 고른다.
2. **실존 인물 + 고증 교육가치** — 가상 캐릭터가 아니라 검증된 사료에 근거한 실제 인물.
3. **사료 근거(RAG) + 출처 표시** — "지어내지 않는 NPC." 고정 대사로는 불가능한, **AI 없이는 존재할 수 없는 게임.**
4. **확장의 방향(비전)** — 동일한 인물 시스템을 재사용해 퍼블릭 도메인·IP 콜라보로 확장. *팬이 게임으로 최애 창작자를 만난다.*

## 7. 플레이 / 기술

- **플레이:** 배포 링크 접속 → 인물 선택 → 설득. (심사 기간 중 링크 제공)
- **기술:** 모바일 반응형 웹 + 서버리스 판정. 상세는 [AI 기술 문서](./AI_TECH.md) 참고.
- **핵심 원칙:** *AI는 배우, 판정은 엔진.* AI가 답을 주지 않고, **인간(플레이어)이 인물의 가치를 판단하고 논거를 선택한다.**
