## 디렉토리 책임 (한 줄 요약)

| 경로 | 책임 | AI 관여 |
|---|---|---|
| `docs/` | 기획·설계 문서, 사료 원본 | ✕ |
| `agents/` | 인물별 페르소나·가치 스키마·사료 저장소 | 데이터(입력) |
| `config/` | 밈·난이도 등 **사실이 아닌** 교체 가능 값 | ✕ |
| `web/src/engine/` | **게이지·턴·승패·등급** — 결정론, 조작 불가 | ✕ |
| `web/` (그 외) | 화면·입력·출처각주·톤토글 | ✕ |
| `server/harness/` | Claude 요청 조립·검증·가드레일 | **판정·대사만** |
| `server/fallback/` | 상한 초과·장애 시 사전 생성 응답 | ✕ |

## 명명 규칙

- **인물 파일:** `agents/<id>.md` (id = 소문자 영문, 예 `sejong`). 파일 하나 = 에이전트 하나.
- **사료 조각 id:** 인물 접두 + 일련번호 (예 세종 `S-01` … `S-07`). 각 조각에 `출처·url·tier` 필수.
- **리서치 파일:** `docs/research/<id>-<시대범위>.md` (예 `sejong-1443-1444.md`).
- **티어:** `1`=1차 사료 원문 · `2`=공신력 기관. 위키/블로그/유튜브는 최종 근거 금지(검색 단서만).

## 경계 원칙 (한 눈에)

- **사실은 `agents/` + `docs/research/`에만.** 코드·config에 역사 사실을 하드코딩하지 않는다.
- **비밀(API 키)은 `server/.env`에만.** 절대 커밋·클라이언트 노출 금지.
- **게임 상태는 `engine/`이 100% 소유.** AI 응답은 상태를 직접 바꾸지 못한다.
- **밈은 `config/memes.json`에만.** 사실 층과 물리적으로 분리.
