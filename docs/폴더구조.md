## 디렉토리 책임 (한 줄)

| 경로 | 책임 | AI 관여 |
|---|---|---|
| `content/characters/<id>/` | 인물 페르소나·가치 축·사료·시나리오 | 데이터(입력) |

## 명명 규칙

- **인물 폴더:** `content/characters/<id>/` (id = 소문자 영문: `sejong`, `vangogh`).
- **인물 데이터 4종:** `profile.json`(성격·가치 축) / `knowledge.json`(사료·RAG) / `debate.json`(쟁점) / `scenario.json`(화면 흐름).
- **사료 조각 id:** 인물 접두 + 번호 (예 `sejong-001`). 각 조각에 `source·sourceUrl·tier` 필수.
- **티어:** `1`=1차 사료 원문 · `2`=공신력 기관. 위키/블로그/유튜브는 최종 근거 금지.
- **파일명은 영어로 통일**(GitHub 업로드 이슈 방지). 내용·게임은 한국어.

## 경계 원칙

- **사실은 `content/` + `docs/research/`에만.** 코드·config에 역사 사실을 하드코딩하지 않는다.
- **비밀(API 키)은 `.env` / 배포 환경변수에만.** 커밋·클라이언트 노출 금지.
- **게임 상태는 `engine/`이 100% 소유.** AI 응답은 상태를 직접 못 바꾼다.
- **밈은 어투에만.** 사료 인용부·역사 사실엔 침투 금지.
