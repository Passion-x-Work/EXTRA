# EXTRA · 60초 데모 대본 (심사 시연용)

> 목적: 60초 안에 **깊이(인물별 다른 공략)** + **AI가 실제로 판정** + **치팅 방지**를 체감시킨다.
> 아래 대사·등급은 **라이브 GPT 실측값**(2026-08-06). **제출·시연 provider = GPT 확정.**
> 촬영 권장: 60초 화면녹화(안전망) + 라이브(임팩트) 병행. 판정 오작동 리스크는 녹화가 흡수.

## 사전 준비 (촬영 전 체크)
- [ ] 판정 프록시 실행: `node server/index.mjs` (health `gpt=true` 확인)
- [ ] 드롭다운 = **GPT**로 고정 (제출·시연 provider 확정)
- [ ] 저장 초기화: 지도에서 이어하기(↺)로 세종·반고흐 저장 삭제, 난이도 = 미디움
- [ ] 대사는 아래 **확정본 그대로** 입력(등급 재현됨)

## 타임라인 (0:00 → 1:00)

### 0:00 — 훅 (지도 화면)
> 🎙️ "역사 인물의 **숨은 가치**를 추리해 설득하는 게임이에요. 인물마다 통하는 논리가 완전히 다릅니다."

### 0:05 — 세종 ① 틀린 직관 (세종 선택 후 입력)
```
이 글자로 우리 민족의 위대함을 온 천하에 떨치십시오!
```
→ **불합치 0** · 게이지 그대로. NPC: "우리 왕국의 자랑은 백성의 안녕과 학문 장려라…"
> 🎙️ "민족 자긍심으로 밀면 안 먹혀요. 세종의 진짜 축은 **애민**이거든요."

### 0:18 — 세종 ② 정답
```
전하께서 백성을 자식처럼 아끼신다면, 억울한 이가 스스로 뜻을 펴 아뢸 수 있는 쉬운 글을 주시는 것이야말로 참된 애민입니다.
```
→ **정합 +35** · 게이지 40→75 + **출처 각주**. NPC: "너의 말이 타당하므로…"
> 🎙️ "사료(어제서문)에 근거해 반응하고, 근거까지 붙어요. 지어내지 않죠."

### 0:32 — 반고흐 ③ 틀린 직관 (뒤로가기 → 반고흐 선택)
```
이제 그만 쉬시고 편하게 사세요.
```
→ **불합치 0** · 게이지 그대로(30). NPC: "쉬라는 말이 오히려 내게는 고통일 것이오."
> 🎙️ "같은 '위로'인데, 고흐한텐 **동정이 독**이에요."

### 0:42 — 반고흐 ④ 정답
```
당신의 색은 언젠가 사람들의 마음에 닿을 겁니다. 팔리지 않아도, 멈추지 말고 계속 그리세요.
```
→ **정합 +35** · 게이지 30→65. NPC: "고맙네, 그대의 말씀에 위안이…"
> 🎙️ "감정·정진 축으로 가야 열려요. **인물마다 정반대로** 작동하죠. AI가 각 인물의 가치관에 맞춰 판정합니다." ← **최강 순간**

### 0:52 — ⑤ 베끼기 응징
- 💡 힌트를 열어 사료 원문을 띄운 뒤, **그 원문을 그대로 복붙**해 입력.
→ **화면 깜빡 + 흔들림 + 토스트 "베끼기는 통하지 않는다" → 2턴 되돌림**
> 🎙️ "힌트를 그대로 베끼면? 되돌아갑니다. **낭독은 설득이 아니에요.**"

### 0:58 — 클로징
> 🎙️ "AI가 답을 주는 게 아니라, **사람이 가치를 판단하고 설득**하는 게임. AI 없이는 만들 수 없죠."

## 검증에서 나온 연출 팁
- **GPT는 '인물 본인의 가치 정체성'으로 프레이밍해야 `정합`을 준다.** "억울한 백성" 단독은 `부분(+15)`, "**백성을 자식처럼 = 참된 애민**"으로 엮으면 `정합(+35)`. ②·④는 이걸 반영한 확정본.
- **틀린 대사(①③)는 안정적으로 0점** + 인물다운 거절 대사 → "안 통함"이 눈에 확 보임.
- **베끼기 응징은 provider 무관(동기 판정)** — GPT/Claude/오프라인 어디서든 즉시 발동.
