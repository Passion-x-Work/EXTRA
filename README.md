# EXTRA

엑스트라(EXTRA) — 역사에 끼어든 단역이 되어 실존 인물을 설득하는 게임
NHN AI 해커톤 · 팀 덕업일치(Passion x Work)

## 소개

검증된 사료로 구현된 실존 역사 인물(AI 에이전트)과 대화하며 설득하는 교육형 웹게임입니다.
플레이어는 역사에 끼어든 단역이 되어, 결정적 순간의 인물을 만나 대화로 설득합니다.

설득에 성공하면 근거가 된 사료를 카드로 획득해 도감에 수집하며,
모은 카드는 더 높은 난이도를 공략하는 자원이 됩니다.

핵심 원칙: **사실은 사료, 말투는 자유.**
인물의 답변은 검증된 사료에 근거하며 환각(사실 왜곡)을 만들지 않습니다.

## 실행 방법

Node.js 18 이상과 npm이 필요합니다. ※버전 확인

```bash
git clone <repository-url>
cd EXTRA
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속합니다.

### AI 판정 모드 (선택)

**API 키가 없어도 게임은 완전히 플레이됩니다.** 키가 없으면 오프라인 휴리스틱
판정으로 자동 폴백하며, 게임 루프·신념게이지·승패 판정이 모두 정상 동작합니다.

Claude를 통한 실제 AI 판정을 쓰려면 프로젝트 루트에 `.env`를 만들고 키를 넣습니다.
※파일명·변수명 확인

```
ANTHROPIC_API_KEY=sk-ant-...
```

두 모드의 차이는 다음과 같습니다.

| | 오프라인 판정 | AI 판정 (Claude) |
|---|---|---|
| API 키 | 불필요 | 필요 |
| 판정 방식 | 키워드 매칭 휴리스틱 | 논거의 내용·맥락 이해 |
| 회피 / 정면응답 구분 | 제한적 | 가능 |
| 인물 응답 | 정형화된 응답 | 매 턴 생성 |
| 용도 | 실행 확인 · 자동 테스트 · 폴백 | 실제 게임 경험 |

## MVP 범위

- **조선 · 세종대왕** — 완전 구현 (1444년 훈민정음 반대 상소 국면)
- **유럽 · 반 고흐** — 맛보기 (짧은 대화) · 퍼블릭 도메인 예술 IP
- **일본 · 미야자키 하야오** — 준비 중 · 서브컬처 IP 콜라보 (NHN 일본 시장)

세 인물은 "위대한 창작자를 세상에 내보낸다"는 하나의 테마로 이어집니다.
(역사·교육 → 예술 IP → 서브컬처 IP 로 확장)

## 게임 흐름

지역 선택 → 시나리오 선택 → 인트로 → 캐릭터 대화(신념게이지) → 결과

## 기술 구성

- 반응형 웹(web) ↔ 게임 로직(server) ↔ Claude API
- 서버 역할: 사료 검색(RAG) · 인물 프롬프트 · 게임 규칙 판정(신념게이지)
- 인물 데이터는 JSON으로 분리 → 인물 추가는 폴더 복사만으로 확장

### 판정 파이프라인

```
입력 정규화 → 인젝션 탐지 → 쟁점·사료 검색 → 판정(턴당 1회)
  → 검증 실패 시 재시도 1회 → 폴백 → 등급 산출 → 게이지 반영
```

판정 결과는 탁월·정합·부분·불합치·역효과 5단계 등급으로 나오고, 등급별 게이지
변동량은 `config/difficulty.json`에 정의됩니다.

숫자는 설정 파일에, 규칙은 엔진에 둡니다. 게이지 시작값(40)·승리(100)·패배(0)
같은 상수는 모두 `config/difficulty.json`에 있고, `applyGrade.js`는 그 값을 읽어
판정만 수행합니다. 난이도 조정이 코드 수정 없이 가능합니다.

사료 조각이 8개 규모인 현 단계에서는 벡터 검색 대신 쟁점–사료 직접 매핑
(`sourceRef`)을 사용합니다. Graph RAG는 이후 로드맵입니다.

자세한 내용은 [docs/하네스-엔지니어링.md](docs/하네스-엔지니어링.md) 참조.

## 사료 관리

모든 인물 데이터는 검증된 사료에 근거하며, 출처 기준과 갱신 정책을 별도로
관리합니다. 자세한 내용은 [docs/RESEARCH_POLICY.md](docs/RESEARCH_POLICY.md) 참조.

## 폴더 구조

    EXTRA/
    ├─ web/       # 프론트엔드 (UI, 화면 흐름)
    │  ├─ index.html
    │  └─ src/    # app.js(게임 루프) · style.css(한지풍 디자인)
    ├─ server/    # 게임 로직
    │  ├─ ai/     # judge.js — 논거 판정 (Claude + 오프라인 폴백)
    │  ├─ engine/ # applyGrade.js — 게이지·승패·등급 계산
    │  └─ rag/    # retrieve.js — 쟁점·사료 검색
    ├─ config/    # difficulty.json — 게이지 상수 · 3모드 · 등급 밴드
    ├─ content/   # 인물별 데이터 (profile, knowledge, debate, scenario)
    ├─ agents/    # 인물별 에이전트 설계 문서
    ├─ docs/      # 프로젝트 문서
    └─ test/      # 오프라인 엔드투엔드 테스트

인물 데이터는 `content/characters/` 아래에 인물별로 격리되어 있고, 엔진은 특정
인물을 알지 못합니다. 새 인물은 JSON 4종을 추가하는 것으로 편입됩니다.

설계 의도는 `agents/*.md`(사람이 읽는 문서)에, 실행에 쓰이는 값은
`content/**/*.json`(엔진이 읽는 데이터)에 둡니다. JSON 키는 한글로 통일하고
파일명만 영어를 사용합니다.

## 현재 상태

세종 수직 슬라이스가 구현되어 있습니다. 지도에서 경복궁을 선택해 세종을 소환하고,
훈민정음 창제를 둘러싼 쟁점으로 논쟁하고, 결과 카드까지 받는 흐름이 처음부터
끝까지 동작합니다.

반 고흐와 미야자키는 지도에 노출되어 있으나 준비 중 상태입니다.
